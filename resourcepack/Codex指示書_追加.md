## 1. ★ 直していただきたいもの（1点）

### サイドバーの行名に**半角スペースが使えません**

`SCOREBOARD_TEXT.txt` が、こうなっています。

```
§e¤ 国庫     §f{貯金}
        ↑ ここに半角スペースがある
```

サイドバーの行の見た目は「スコアボードの**保持者の名前**」そのもので、
その名前は**コマンドの引数**として渡します。**空白が入ると命令が壊れます。**

**本物の 1.20.1 サーバーで実測しました。**

| 試したもの | 結果 |
|---|---|
| `scoreboard players set §e国庫 hyouji_1 7` | **通る**（色コードは使える） |
| `scoreboard players set §6❖時代記 hyouji_1 7` | **通る**（記号も使える） |
| `scoreboard players set §e¤ 国庫 hyouji_1 7` | **エラー** `Expected whitespace to end one argument` |
| `scoreboard players set "§e¤ 国庫" hyouji_1 7` | **エラー**（**引用符でも通りません**） |

**お願い**: 行名から**空白を完全に取り除いた**版をください。

```
§6❖時代記        ← 見出し
§e¤国庫          ← 空白なし
§a◆油蔵
§d›領国暦
§b◎中央暦
```

- 記号と文字の間を空けたい場合は、**空白の代わりに使える文字**（全角スペース `　` や
  `･` など）で試作していただき、**どれを使ったかを明記**してください。
  全角スペースが引数として通るかは、こちらで実測して報告します。
- 値（数字）は右端に自動で右詰めされるので、**桁合わせの空白は不要**です。

## 2. ★ 足りていない画面（2つ）

前回の仕様書で「括弧つき（今回の依頼に入っていない）」と書いた2画面ですが、
**実際のゲームには存在し、参加者が毎回開きます。** 同じ世界観で作ってください。

### (A) 銃器専門店 ── **176 × 150 px**（2段・18枠）

銃9丁と弾6種を売る店です。販売所とは**別の建物**という位置づけ。

```
1段目 [0][1][2][3][4][5][6][7][8]   銃9丁（左から時代順）
2段目 [9][10][11][12][13][14] 15 16 17   弾6種 / 15〜17 は空き
```

- **1段目は9枠すべて埋まります。** 仕切りを描くなら枠の外に。
- 2段目の右3枠（15〜17）は空きなので、絵で使って構いません。
- 銃 = 中世〜現代の武器なので、**販売所より硬質・危険な印象**が合います。

### (B) 宣戦する相手を選ぶ ── **176 × 132 px**（1段・9枠）

戦争を始める画面です。**取り返しがつかない操作**なので、
「ここから先は戻れない」と分かる見た目にしてください。

```
 0  [1] [2] [3] [4] [5]  6   7   8
     相手の勢力が並ぶ（最大4つ）
```

- 1〜5 に他勢力が並びます（自分を除く4つ＋余り1）。
- 0 / 6 / 7 / 8 は空き。

### ファイル名

前回と同じ並びでお願いします。

```
assets/jidai/textures/gui/juki.png      （銃器専門店）
assets/jidai/textures/gui/sensen.png    （宣戦）
```

`default.json` と `title_map.json` にも、**私用領域の文字を2つ追加**してください。

前回 使ったのは次の5つです（納品物から読み取りました）。

| 用途 | 文字 |
|---|---|
| 左へ戻す負の幅 | `U+F801` |
| ガチャ / 販売所 / 時代を進める / 銀行 | `U+EDE1` 〜 `U+EDE4` |

**空いている次の2つ、`U+EDE5`（銃器専門店）と `U+EDE6`（宣戦）を使ってください。**
負の幅は前回と同じ `U+F801` を使い回して構いません。
