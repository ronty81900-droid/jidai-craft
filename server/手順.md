# 時代クラフト MODサーバー ── 手順（Minecraft 1.20.1）

`start.bat` をダブルクリックすれば起動します。**必要なものは全部入っています。**

| 中身 | 何か |
|---|---|
| `arclight-forge-1.20.1-1.0.6.jar` | サーバー本体（**Arclight** = Forge 47.3.22 + Bukkit） |
| `mods/tacz-1.20.1-1.1.8-hotfix.jar` | [TaCZ] Timeless and Classics Zero Guns |
| `mods/voicechat-forge-1.20.1-2.6.22.jar` | Simple Voice Chat |
| `tacz/GunpowderRevolution_gunpack_v1.2.7_naoshi.zip` | 銃のパック（第一次大戦・36丁） |
| `plugins/JidaiCraft-0.20.0.jar` | 時代クラフトのプラグイン |
| `world/` | 1500版の地図 |
| `world/datapacks/jidai_craft` | データパック |
| `libraries/` | Forge の部品（**取得済み**。初回起動が速く済みます） |
| `start.bat` | 起動（メモリ **8GB**） |

---

## ★★ なぜ Arclight なのか ★★

**Paper は MOD を読み込めません。Forge は Bukkit プラグインを読み込めません。**
両方を動かせるのは「ハイブリッドサーバー」だけです。

Arclight は Forge の中に Bukkit を埋め込んだもので、
**MOD（TaCZ・Simple Voice Chat）とプラグイン（JidaiCraft）が同居できます。**

> **★ そのために JidaiCraft を1箇所だけ作り替えました（2026-08-20）。**
> Arclight は Bukkit / Spigot の API しか持たず、**Paper 専用の Adventure が使えません**。
> そこで通知の色を「§ + 1文字」の色コードに落としました。**見た目は変わりません。**
> 逆戻りしないよう、検証が毎回「`net.kyori` の import が1つも無いこと」を見ています。

## 参加者50人に必要なもの

**全員のクライアントに、次の3つが要ります。** 1つでも欠けると入れません。

1. **Minecraft 1.20.1**
2. **Forge 47.3.22**（1.20.1 用）
3. **MOD 2つ**（`.minecraft/mods` へ）
   - `tacz-1.20.1-1.1.8-hotfix.jar`
   - `voicechat-forge-1.20.1-2.6.22.jar`
4. **銃のパック**（`.minecraft/tacz` へ）
   - `GunpowderRevolution_gunpack_v1.2.7_naoshi.zip`

**`クライアント用/` フォルダにまとめてあります。** これをそのまま配ってください
（3ファイル・73MB。入れ方を書いた `はじめにお読みください.md` も同梱）。

> **★ 参加者が `This server has mods that require Forge…` で止まる時は、
> Forge が入っていないか、ランチャーで forge の起動構成を選んでいません。**
> サーバーは **Forge 47.3.22** で動いています。版を合わせてください。
> （`simplebedrockmodel` は TaCZ の jar に同梱なので、別途入れる必要はありません）

> **★ Simple Voice Chat は UDP の 24454番 を使います。**
> 外から繋いでもらうなら、TCP 25565 に加えて **UDP 24454 も開けてください。**
> 設定は `config/voicechat/voicechat-server.properties` にあります。

## 起動したら ── **これ1つで済みます**

```
jidai setup
```

（ゲーム内からなら `/jidai setup`）

拠点を建て、プラグインに覚えさせるところまで全部やります。**打つのは1回だけ。**

```
[設置] 始めます。区画を読み込むので 5秒ほどかかります
[設置] 施設が 37 / 37 個 建ちました
[設置] 登録しました: 販売所 6 / 銃器専門店 5 / 銀行 5 / ガチャ 5 / 進行 5 / かまど 10
[設置] 完了です。次は勢力へ入れてください (team join kyuryo <名前>)
```

足りなければ**自動で3回までやり直します**。3回とも駄目な時だけ理由を出して止まります。

### ★ 各拠点のビーコンを登録してください（勝利条件に要ります）

拠点のビーコンの上に立って、**勢力名つきで**登録します。

```
jidai beacon kyuryo
```

`kyuryo` `shinrin` `kawa` `naikai` `iwaba` を5拠点ぶん。
これをしないと「戦争勝利」（拠点を落として植民地にする）が起きません。

### ★ ツルハシは自動で配られます

参加者が初めて入った時に「**時代のツルハシ**」が1本 渡ります。
**壊れず、死んでも落としません。** 運営が打つことは何もありません。

無くした人にだけ、渡し直してください。

```
jidai tsuruhashi <名前>
```

そのあと勢力へ入れてください。

```
team join kyuryo <名前>
```

チーム名は `kyuryo`(丘陵) `shinrin`(森林) `kawa`(川) `naikai`(内海) `iwaba`(岩場)。

## リソースパック（UI の絵）── **配りません**（2026-08-21 決定）

**買い物画面はクライアント側の MOD（`時代クラフト/clientmod/`）が描きます。**
リソースパックでチェスト画面を差し替える方式は取りやめました。

- **参加者に配るのは3ファイルのまま**（銃の MOD / 音声チャット / 銃のデータ）
- `server.properties` の `resource-pack=` は**設定しません**
- `jidai ui on` は**押しません**（既定の `off` のまま）

> **★ 押しても、入れても、得はありません。**
> 既定 `off` では絵は出ません。それでいてパックを入れた人は
> `container.inventory` の上書きにより**「持ち物」の字が全画面から消えます**。
> 詳しくはルートの `README.md`。

納品物（4案）は `時代クラフト/resourcepack/codex/` に残してあります。消さないでください。

| `jidai sekiyu` | 石油の栓の今の状態 |

## 建築を壊す設定は、こちらで切ってあります

`config/tacz-common.toml` の3つを **false** にしました（2026-08-20）。

```toml
ExplosiveAmmoDestroysBlock = false   ← 榴弾・ロケットがブロックを壊す
IgniteBlock                = false   ← 弾がブロックに火を付ける（原木・木の板が燃える）
DestroyGlass               = false   ← 弾がガラスを割る
```

**時代クラフトは「建築量」で時代が進む企画**なので、銃で拠点を壊せると設計が崩れます。
戻すなら `true` に書き換えてください。元のファイルは `tacz-common.toml.moto` にあります。

> 全パックを調べたところ、`explode:true` を持つのは **M320 / RPG-7 / `ammo_mod_he`（HE弾モジュール）の3つだけ**でした。
> `ammo_mod_he` は**アタッチメントなのでどの銃にも付けられます**が、上の設定1つで全部止まります。
> ブロックに火を付けるのは `flaregun`（信号拳銃）1丁だけです。

## 拠点に何がどこに建つか

すべて拠点の中心から **Z が +6** の一列です（実測）。

| 施設 | 中心からの位置 | ブロック |
|---|---|---|
| 銀行 | x+0, z+6 | 金ブロック |
| 販売所 | x+4, z+6 | エメラルドブロック |
| ガチャ | x+7, z+6 | ダイヤブロック |
| **銃器専門店** | **x+10, z+6** | **エメラルドブロック** |
| 時代を進める | x-4, z+6 | 鉄ブロック |
| エンダーかまど1 | x-8, z+6 | かまど |
| エンダーかまど2 | x-10, z+6 | かまど |

> ★★ 販売所と銃器専門店は**どちらもエメラルドブロック**です ★★
> 見分けているのは置いてある場所（登録）で、ブロックの種類ではありません。
> 押して違う店が開く時は `jidai list` で確かめ、
> そのブロックの上で `jidai remove` → `jidai juki`（または `jidai add`）で直せます。

拠点の中心は
拠点1 `(0,-410)` / 拠点2 `(390,-127)` / 拠点3 `(241,332)` /
拠点4 `(-241,332)` / 拠点5 `(-390,-127)`。

押しても何も起きない時は `jidai scan`。今の状態は `jidai list`。

## 銃のパックについて（1つ直してあります）

配布されている `GunpowderRevolution_gunpack v1.2.7.zip` は、
**登録簿に42丁あるのに、中身は36丁しか入っていません**（パック側の不備）。

そのまま入れると、起動のたびに赤いエラーが6件出ます。

```
ERROR [tacz/GunIndexLoader]: Failed to load data file hamster:colt1873_lb
com.google.gson.JsonParseException: there is no corresponding data file
```

**中身の無い6丁への参照だけを外した zip** を置いてあります（`_naoshi` 付き）。
実際に起動して **エラー0件** になることを確かめました。
外したのは次の6つで、**遊べる銃は減っていません**（もともと入っていなかったもの）。

```
colt1873_lb / coltm1851_chain / lebel1886_07c
lugerp08_artillerie / m1887_hc / uppercut
```

元のファイルは `tacz/_moto_….zip.bak` に残してあります。
