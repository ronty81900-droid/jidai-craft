### 2-3. 戦争（**プラグインは勢力名の保持者だけを読む**）

> **★★ 1.20.1 移行で、ここだけ作りが変わりました ★★**
> 1.21 では保持者 `丘陵>森林` のスコアで戦争を持っていました。
> その名前はマクロ（`$(...)`）でしか作れず、**1.20.1 にマクロがありません**（実測）。
> そこで **マーカー1体＝戦争1件** に変えました。
> マーカーのスコアは「そのマーカーとして」でないと読めないため、
> データパックが毎秒**勢力名の保持者へ写し直します**（`jidai:sensou/youyaku`）。
> **プラグインはマーカーを読まないでください。** 下の表だけを見ます。

| 目的名（保持者＝**勢力名**） | 意味 | 値 |
|---|---|---|
| `sensou` | 戦争の状態 | **0=なし / 1=準備 / 2=交戦 / 3=再戦禁止** |
| `sensou_aite` | 交戦相手の**番号** | 0=なし / 1〜5 |
| `sensou_byou` | 今の状態の残り秒 | 秒 |

- 1勢力が同時に持てる戦争は **1つだけ**（要約は最初に見つけた1件を写す）
- **毎秒作り直される派生値です。** プラグインが書き込んではいけません
- `sensou_tsuyosa` は毎秒リセットされる作業用。読まないでください

### 2-5. `settei`（保持者＝設定項目名）

読むだけ。プラグインは書かない。**ただし下の2つだけは例外。**

#### ★ 例外: 石油の栓（2026-08-20 追加）

| 保持者 | 意味 | 誰が書くか |
|---|---|---|
| `石油_停止` | 1 なら中央プラントが1本も出さない | **プラグイン**（`jidai sekiyu tomeru` / `hajimeru`） |
| `石油_倍率` | 湧く速さの百分率。100 が通常、50 で半分 | **プラグイン**（`jidai sekiyu osaeru <1〜100>`） |

> **なぜ例外にしてよいか**
> データパックはこの2つを `scoreboard players add 石油_停止 settei 0` のように
> **「無ければ作る・あればそのまま」** で置いており、毎秒上書きしない。
> 他の `settei` は `execute unless … matches 1..` で初期値を決めるだけなので、
> プラグインが書いても読み込み直しで戻ってしまう。
> **書いてよいのはこの2つだけ。**
>
> `clock` 側の使い方:
> - `石油_間隔秒 *= 100` してから `/= 石油_倍率`（先に割ると整数で 0 になる）
> - `石油_停止` が 1 の間は `#plant_t` を 0 に戻す（再開時にまとめて湧かないため）
> - `石油_倍率` が 0 だと割り算が黙って捨てられるので、`load` が 1 以上を保証する

| 保持者 | 既定値 |
|---|---|
| `傭兵_最低額` | 中央の時代に応じてデータパックが毎秒書く |
| `戦争_準備秒` / `戦争_交戦秒` / `戦争_禁止秒` | 300 / 600 / 1800 |
| `略奪_金` / `略奪_石油` / `略奪_間隔秒` | 30 / 2 / 10 |
| `略奪_上限金` / `略奪_上限石油` | 300 / 10 |
| `下剋上_値段` / `下剋上_解禁時代` | 150 / 3（近代） |

## 3. プラグインが呼ぶ関数

> **`@s` を見る関数は、必ず `execute as <名前> at <名前> run function ...` で本人として走らせる。**
> 参加者に `/function` の権限は与えないので、コンソールから実行する。

> **★★ 1.20.1 に関数の引数（マクロ）はありません ★★**
> 引数は **先にスコアへ置いてから** 関数を呼ぶ形に変えました。
> `function ... {kuni:"丘陵"}` と書くと `Incorrect argument` で落ちます（実測）。

| 関数 | 誰として | 先に置くスコア |
|---|---|---|
| `jidai:sensou/sensen` | 誰でもよい | `#w_kuni` `#w_aite` `#w_soku`（目的 `sagyou`） |
| `jidai:sensou/gekokujo_kau` | **買う本人** | なし |
| `jidai:sensou/gekokujo_tsukau` | **リーダー本人** | なし |

### 宣戦

```
scoreboard players set #w_kuni sagyou 1     ← 宣戦する側の番号
scoreboard players set #w_aite sagyou 2     ← される側の番号
scoreboard players set #w_soku sagyou 0     ← 0=ふつう / 1=即交戦
function jidai:sensou/sensen
```

| スコア | 意味 |
|---|---|
| `#w_kuni` | 宣戦する側の**番号**（1〜5。勢力名でもチーム名でもない） |
| `#w_aite` | 宣戦される側の**番号** |
| `#w_soku` | `0`=ふつう（準備5分から）/ `1`=即交戦・略奪上限2倍（**下剋上専用**） |

- **3つとも必ず置くこと。** 前回の値が残っていると別の戦争が始まる
- 番号は `bangou` 目的で引ける（`scoreboard players get 丘陵 bangou` → 1）
- 範囲外の番号・自分自身への宣戦・再戦禁止中は**黙って弾かれる**（`#w_soku 1` だけは再戦禁止を無視する）
- **開戦の全体通知・演出はデータパックが出す。** プラグインは出さない

> **★★ 断られたことは、呼び出し側からは分からない ★★**
> `sensen` は条件に合わないと `return 0` するだけで、
> **命令そのものは成功したように見えます**（実測で確認済み）。
> （1.20.1 に `return fail` は無いので `return 0` に置き換えてあります）
> プラグインは 戦争宣誓 の代金 100 を先に引くので、
> 呼んだあとに **`jidai:sensou/youyaku` を呼んでから** `sensou` を読み直し、
> **1以上になっていなければ返金**します。
> （要約はデータパックの時計も毎秒回していますが、GUI の返事は待てないので
> プラグインから明示的に呼びます）
> 同じ理由で、`gekokujo_tsukau` の結果も `senryou` を読み直して判定します。
> **この「呼んだあとに状態を読み直す」約束を崩さないでください。**

### 下剋上

- **値段も上限も解禁時代も、権利の消費も、すべてデータパックが持つ。**
  プラグインは金を引いてはいけない（**引くと二重取りになる**）
- `gekokujo_tsukau` は自前で4つの門番（勢力・リーダー・権利・占領）を通す
