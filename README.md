# 時代クラフト

Minecraft Java版 1.20.1 の大型企画です。5つの勢力が鉄器時代から出発して、未来への到達を競います。

ここには、この企画を動かすのに要る自作物が入っています。他人が作った MOD とサーバー本体は入っていません。入手先は [外部ファイル.md](外部ファイル.md) にまとめました。

## 入っているもの

| 場所 | 中身 | 置き先 |
|---|---|---|
| `world/` | 遊ぶ舞台。1500×1500、5勢力の拠点つき | サーバーの `world/` |
| `plugin/JidaiCraft-0.56.0.jar` | プラグイン。金・店・ガチャ・戦争 | `plugins/` |
| `datapacks/jidai_craft/` | データパック。時代進行・勝利判定・スコア | `world/datapacks/`（すでに `world/` の中に入れた状態で配っています） |
| `clientmod/JidaiUI-0.1.0.jar` | 参加者が入れるクライアント MOD。画面を見やすくします | 各自の `mods/` |
| `server/` | サーバー設定のひな型 | サーバーの直下 |
| `docs/` | 説明書・確認リスト・引き継ぎ書 | 読む物 |
| `tools/gunpack_naosu.py` | 銃パックから使わない6丁を消す道具 | [外部ファイル.md](外部ファイル.md) を参照 |
| `resourcepack/` | 旧方式の名残。今は使っていません | ― |

作り直したい人向けに、元のコードと検査も入れてあります。`plugin/src/` と `plugin/tests/`、`clientmod/src/` `clientmod/ui/` `clientmod/tools/`、それに文書と実装のズレを見る `tests/` です。

## 動かすまで

### 1. 外部ファイルを用意する

[外部ファイル.md](外部ファイル.md) に挙げた5点を落としてください。サーバー本体、MOD 2つ、銃パック、Forge の部品です。著作権があるので、ここには入れられません。

### 2. サーバーのフォルダを組む

```
サーバー/
├── arclight-forge-1.20.1-1.0.6.jar   ← 自分で落とす
├── mods/                              ← 自分で落とす（TaCZ / Voice Chat）
├── tacz/                              ← 自分で落とす（銃パック・6丁 消した物）
├── plugins/JidaiCraft-0.56.0.jar      ← ここから
├── world/                             ← ここから（datapack 入り）
└── （server/ の中身を全部ここへ）      ← ここから
```

### 3. 起動する

```bash
start.bat
```

メモリ 8GB と Java 17 が要ります。初回は Forge が部品を落としに行くので、しばらくかかります。

### 4. 参加者に配る

各自の `mods/` に `clientmod/JidaiUI-0.1.0.jar` を入れてもらいます。TaCZ と Simple Voice Chat も各自で入れてもらいますが、版はサーバーと必ず揃えてください。銃パックは各自の `tacz/` へ。

説明書は下に書いたとおり、別に配ります。

## 説明書の PDF 2冊は別に配ります

合計 72MB あるので、ここには入れていません。運営から参加者へ直接 渡してください。

| | ページ | 誰に |
|---|---:|---|
| 遊び方 | 12 | 参加者 全員。開始10分前に読めば遊べます |
| 詳細版 | 13 | 勢力のリーダー。数字がすべて載っています |

中身が実装と食い違っていないかは、機械で確かめられます。

```bash
python tests/nouhin_kakunin.py <PDFを展開したフォルダ>
```

作り直したくなったときのために、仕様書は `docs/Codex依頼文_説明書A_遊び方.md` と `docs/Codex依頼文_説明書B_詳細版.md` に残してあります。`docs/資料_商品一覧.md` と合わせて外注に渡せば、同じ物が作れます。

## 本番の前に見ておくこと

**遊んだ跡が残っています。** `world/` は開発中に遊んだ世界そのものです。参加者ごとの記録（持ち物・進捗・統計）は抜いてありますが、スコアは残っています。本番の前に、サーバーのコンソールで一度リセットしてください。

```
jidai game reset zenbu
```

**設定が開発中の値のままです。** `server/server.properties` の3つを見直してください。

| 項目 | 今の値 | 本番でどうするか |
|---|---|---|
| `difficulty` | `peaceful` | 敵を出すなら `normal` |
| `max-players` | `60` | 参加人数に合わせる |
| `online-mode` | `true` | そのまま |

**運営権限は入っていません。** `ops.json` や `whitelist.json` は個人情報なので、わざと外してあります。起動後にコンソールから付けてください。

```
op <自分の名前>
```

## 遊び方の要点

勢力は丘陵・森林・川・内海・岩場の5つで、参加者は全員どれかに入ります。時代は鉄器 → 中世 → 近代 → 現代 → 未来の5段階です。

勝ち方は4つあります。戦争、経済、超特殊、それに本命の未来到達です。同じ勢力の仲間は殴れません。敵勢力を倒すと、相手の所持金の10%を奪えます。

詳しくは `docs/ゲームマスター説明書.md` を読んでください。

## 開発するなら

この環境では Gradle が動きません（Java の NIO Selector が塞がれているためです）。`.jar` は `javac` と `zipfile` で組んでいます。

```bash
python clientmod/build.py
```

```bash
python plugin/tests/run_harness.py
```

検査はサーバーを立てずに 1,032件 走ります。`sun.misc.Unsafe` と `Proxy` で Bukkit を偽装しているからです。実際にサーバーを立てて通す検査は `tests/verify_jidai.py` で、こちらは 404件 です。

作業の作法とこれまでの経緯は、`docs/開発の引き継ぎ書.md` に全部書いてあります。
