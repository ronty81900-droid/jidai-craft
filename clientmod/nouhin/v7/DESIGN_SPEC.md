## 作り方（指示文 §2 の条件①②を守る）

1. 形を 円・多角形・帯 などの図形（符号付き距離）で本番の解像度に描く
2. 面は 球・円柱・面 の陰影を段階色で付け、素材ごとの模様（木目・革の粒・石のまだら・紙のむら・鉄の刷毛目）を画素単位で入れる
3. 形の縁を格子に寄せる: 格子ごとに「入る側 78% 以上／出る側 22% 以下」（アルファ 25% の内側）
4. 輪郭は透明に接する格子だけに 0.50 格子の帯。その内側は素材の一番暗い色
5. 下絵（16×16）は本番の【格子の中心の画素】＝ 条件①の定義そのもの。格子の平均が外れた所は同じ素材の段を1つ寄せる

| 条件 | 定義 | 確かめ方 |
|---|---|---|
| ① nearest | `本番[S/2::S, S/2::S] == 下絵`（S = 格子の一辺。Pillow の NEAREST と同じ「中心を拾う」） | 吐いた byte を読み直して照合 |
| ② 平均 | 格子ごとに アルファの平均が下絵から 25% 以内。下絵が不透明なら 不透明画素の RGB 平均が各成分 40 以内 | 全格子を numpy で数える |

## 共通の作図規約（指示文 §3）

- 背景 `#00000000`、不透明度は 0 か 255 だけ。ぼかし・発光・半透明・グラデーション・アンチエイリアス無し
- 完全に透明な画素の RGB は 0,0,0
- 輪郭は `outline` (#102329)。透明に接する格子にだけ置く。素材面の内側は色面の境界だけ
- 光源は左上。`highlight` (#F5DE9B) は1枚に1つの連結したまとまりだけ
- 経年の傷・欠け・煤は1枚に1か所
- 外周の透明余白は 1格子（512: 32px / 256: 16px）
- 読める文字・数字・ロゴ・実在メーカーの UI は無い。長方形の角は直角
- 色は v6 の共有パレット 52 色から。足した色: 無し

## manifest

- `manifest.json` は根の直下。`files` の各項目に `category`（`item_texture` / `shitae` / `preview` / `preview_shitae`）・`sha256`（大文字）・`dimensions` を入れている
- `preview/` は本番を nearest で 1/2 に縮めた物。`preview_shitae/` は下絵を nearest で 8倍にした物。どちらも同じ実行で吐く
- 検査: `python tests/tokushu_e_kakunin.py clientmod/nouhin/v7`
