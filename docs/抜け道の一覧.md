## A. 経済・物のやり取り

### A-1 ◎ 蛮族を通した「銃の密輸」

**勢力 → 石油を蛮族へ手渡し → 蛮族が 1本12円で換金 → 蛮族の店の銃を買う → 手渡しで勢力へ**

**銃器専門店の「勢力の貯金が 10,000 を超える」という門を通さずに、銃が手に入ります。**

| | |
|---|---|
| 確かめ方 | `Shop.YOUHEI_JUKI` に貯金の門が無い（時代の門だけ）／`JidaiCraft.java` に `PlayerDropItemEvent` のハンドラが無い |
| 代償 | ルガー P08 は 600円 ＝ **石油50本**。鉄器の進行に要る100本の半分。払う側の進行は確実に遅れる |
| 強さの上限 | 蛮族の銃の最強は AKM（威力9）。勢力の M107（威力55）は超えない |
| 裏切りの余地 | 蛮族が受け取って渡さない自由がある |

**残します。**「取引」そのものなので。

### A-2 ▲ 石油をチェストに入れると腐らない

**腐敗が数えるのは【預けた分（スコア）＋ 本人の持ち物】だけです。チェストの中は数えません。**

| | |
|---|---|
| 確かめ方 | `fuhai/mochi.mcfunction` が `clear @s ... 0` で**本人の持ち物だけ**を数えている |
| 何が起きるか | 石油をアイテムで引き出してチェストへ入れれば、**腐敗を完全に回避**できる。保有上限（必要量×1.2）も回避できる |
| 度が過ぎると | 腐敗は「現代到達が約65分 変わる」いちばん強いブレーキ。ここを抜けられると、進行が大きく速くなる |

**塞ぐなら**: 拠点の周りのチェストを毎秒 数える形にする（`clone filtered` と同じやり方で可能）。**重くなるので、実機で1回まわしてから決めるのを勧めます。**

### A-3 ◎ 石油の貸し借りで、時代の条件を満たす

**時代を進める条件の石油は「持っているか」を見るだけで、進んでも減りません。**

| | |
|---|---|
| 確かめ方 | `shinko/hantei.mcfunction` は `#sekiyu >= #hitsuyo` を見るだけ。`shounin_*.mcfunction` が引くのは**貯金だけ** |
| 何ができるか | 申請の直前に他勢力から石油を借り（`/trigger sekiyu_dashi` で引き出して手渡し）、承認後に返す |
| ★ 未来到達も同じ | 石油500本は「申請の瞬間に持っていればよい」。**借りて勝てます** |

**残します。** データパック側にも「バニラには相手を指定した送金が無いので、これ（引き出し）が取引の手段になる」と書いてあり、**貸し借りは設計に入っています**。
ただし**未来到達＝勝利**なので、そこだけ塞ぐ選択はあります（▲）。

### A-4 ○ 蛮族に貴金属を掘らせても、勢力の得にはならない

金（個人の金）は**受け渡せません**（スコアで、送金コマンドも無い）。蛮族が稼いだ金は蛮族の物です。
**勢力が得られるのは「蛮族が買った物」だけ**です（A-1）。

## B. 戦争

### B-1 ◎ 略奪だけでは貯金を 0 にできない

1交戦の上限は **金300・石油10**。貯金15,000を削り切れません。
**「相手が時代を進めた直後（貯金を使い切った所）」を狙うのが唯一の現実解**です。

これは設計として `docs/クリア想定時間.md` にも書いてあります。**残します。**

### B-2 ○ 拠点の建材を壊せば、相手の進行が止まる

建築の判定は「拠点の中に置かれた丸石・原木・板・石レンガ・かまどの**今の個数**」です。
敵が入って壊せば数が減り、**申請できなくなります**。

| | |
|---|---|
| 確かめ方 | `shinko/kenchiku.mcfunction` が `clone filtered` で毎回 数え直している |
| 未来到達では特に効く | 建材2,400個が壁なので、**壊しに行くのが有効な妨害**になる |

**残します。** 終盤の攻防になります。

### B-3 ○ 建築は「丸石を積むだけ」でよい

テンプレート照合はしていません（コメントに「全員が同じ建物を建てることになり、建築の楽しさが死ぬため」と明記）。
**見た目のよい建物でなくても条件は満たせます。**

## C. 傭兵・蛮族

### C-1 ▲ 雇われて、何もしない

**契約中の裏切りに罰がありません。** 企画案にあった「裏切ったら移籍・名前の色が変わる」は**未実装**です。
石油をもらって離れても、システム上は何も起きません。

**塞ぐなら**: `/headhunt` と同じ形で「雇い主が契約を切る」口を作るのが素直です。
**残すなら**: 「信用が通貨になる」遊びとして成立します。

### C-2 ◎ 引き抜き合戦

`/headhunt` は**現在の契約額より高い額**を出せば通ります。上限はありません。

### C-3 ○ 蛮族はプラントの近くに湧く

未雇用の蛮族のリスポーンは**プラントから20〜100ブロック**（`jidai game risu youhei`）。
**石油をいちばん早く拾える位置**にいます。蛮族の利点として残します。

## E. ★ ここは塞いであります（確認済み）

| | どう塞いであるか |
|---|---|
| 勢力が石油を蛮族に預けて腐敗を逃れる | 蛮族にも腐敗が効く（`fuhai/youhei.mcfunction`）。しかも勢力の合計に入らないので、預けても意味が無い |
