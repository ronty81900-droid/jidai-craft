# 運営コマンドブロック ── ゲームマスターの手引き

> 場所: ゲーム開始位置の脇（X=37, Y=175, Z=-938 付近）。
> ここに並べたコマンドブロックから、ゲーム全体を動かす（2026-08-22 のご指示）。

すべて **`/jidai game …`** の形。**コマンドブロックから打てる**（送り手を問わない）。
例外は「自分の足元」を使う `spawn here` と `kyoten <勢力>` の2つだけ（ゲーム内から打つ）。

---

## 1. コマンドブロックに入れる中身

| ボタン | コマンド | 何が起きるか |
|---|---|---|
| **開始** | `jidai game start` | 石油の栓を開ける・全員に「ゲーム開始」のタイトルと音 |
| **停止** | `jidai game stop` | 石油の栓を閉める・全員に「ゲーム停止」 |
| **時代のリセット** | `jidai game reset` | 中央の時代=鉄器 / 5勢力の時代=鉄器 / 湧いた石油の本数=0 / 銃器専門店の解放を取り消し / 中央ビーコンとプラントの見た目を鉄器へ |
| **全部リセット** | `jidai game reset zenbu` | 上に加えて **貯金・個人の金・石油・占領・植民地・下剋上・勝利・戦争** を消す（企画のやり直し用） |
| **拠点へ集合** | `jidai game tp kyoten` | 勢力に所属する全員（契約中の傭兵も）を、その勢力の拠点へ |
| **リスポーン＝拠点** | `jidai game risu` | 勢力の全員のリスポーンを拠点にする。**以後に入った人も、死ねば拠点に戻る** |
| **拠点のビーコン** | `jidai game beacon` | 5拠点の**後方**に 鉄3×3＋ビーコン＋勢力色のガラス を置いて登録する（先に `/jidai scan`）。相手の貯金が **100 以下**で交戦中なら壊せる。壊すと終戦（花火5発） |
| **状態を見る** | `jidai game` | 開始/停止・石油・初期リスポーン・拠点の位置の一覧 |

★ コマンドブロックには **スラッシュを付けない**（付けても動くが、慣例として付けない）。
★ コマンドブロックの「前回の出力」に結果が出る。人数や「未登録」の知らせはそこで読める。

### ゲーム開始の手順（おすすめの並び）

```
1. jidai game reset zenbu   ← まっさらにする（練習の痕跡を消す）
2. jidai game risu          ← リスポーンを拠点に
3. jidai game tp kyoten     ← 勢力を拠点へ
5. jidai game start         ← 石油が湧き始める
```

チェーンコマンドブロックで 1→5 をつなげば、ボタン1つで始められる。

## 2. 初期リスポーン

**世界のスポーン = (40, 176, -927)**（ご指示の座標）。
プラグインが起動のたびに世界へ書き込むので、`/setworldspawn` を打ち直す必要はない。

変えたい時:

| | |
|---|---|
| `jidai game spawn` | 今の値を見る |
| `jidai game spawn here` | 自分の足元にする（ゲーム内から） |
| `jidai game spawn 40 176 -927` | 座標で指定（コマンドブロックからも可） |

## 3. 拠点の位置はどう決まるか

**座標は書いていない。** `/jidai scan` を打った時に、データパックが施設マーカーに付けた
`jidai_kyoten_<勢力>` の印から **施設の並びの2ブロック手前（+z）** を自動で求める。
地図を作り直しても、`/jidai scan` を打ち直せば追随する。

自動の位置が気に入らなければ、その場所に立って

```
jidai game kyoten kyuryo
```

（勢力: kyuryo / shinrin / kawa / naikai / iwaba）。手で決めた値は走査で消えない。

傭兵の基準になる **石油プラントの位置**も `/jidai scan` で覚える。
`jidai game` で「未登録」と出たら、先に `/jidai scan`。

---

## 4. 止めた時に止まらないもの

`stop` が止めるのは **石油の栓**だけ。データパックの時計（戦争・腐敗・時代判定・サイドバー）は
動き続ける。時計ごと止めると、サイドバーも所持金の帯も止まり、参加者には
「止めた」のか「壊れた」のか見分けがつかないため。

戦争や腐敗も止めたい時は、その場で `jidai game reset zenbu` で戦争を消すか、
データパック側の設定（`settei`）で猶予を伸ばす。

## 5. 検証

`python plugin/tests/run_harness.py` の **KanriTest** が見ている:

- リセットが「書くべきスコアだけ」を書き、**金や徴収の世代（choshu）に触らない**こと
  （choshu を戻すと、全員が未徴収扱いになって石油を4割 取られる）
- 傭兵の飛び先が 90〜110 ブロックに収まり、1人ずつ別の場所になること（2000回）
- `game` がプレイヤー限定の門番より **前**にあること（＝コマンドブロックで弾かれない）
