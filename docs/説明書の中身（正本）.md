## 2. 時代を進める条件（実装から）

| 今の時代 | → 次 | 石油 | 貯金 | 建材 |
|---|---|---:|---:|---:|
| 鉄器 | 中世 | 100 本 | 5,000 円 | 200 個 |
| 中世 | 近代 | 250 本 | 15,000 円 | 400 個 |
| 近代 | 現代 | 500 本 | 50,000 円 | 800 個 |
| 現代 | **未来** | 500 本 | 0 円 | 2,400 個 |

> **★ 現代 → 未来 だけ、貯金は要りません**（0円）。石油と建材の2つだけです。
> **★ 条件が揃っても自動では進みません。** 申請すると運営が承認して初めて進みます。

### 進行を邪魔するもの

| | 中身 |
|---|---|
| **腐敗** | 石油は **15分ごとに 10%** 減る（いちばん効くブレーキ） |
| **徴収** | 中央の時代が上がると、全勢力から石油を **40%** 取る |
| **先行ペナルティ** | 中央より先へ進んでいる間、預ける石油が **50%** に減る |

## 3. 戦争（実装から）

| | |
|---|---|
| 始め方 | 販売所で**戦争宣誓**を買い、相手を選ぶ |
| 準備 | **5分**（この間は略奪できない） |
| 交戦 | **10分** |
| 再戦禁止 | **30分** |
| 略奪 | 敵拠点の金ブロックを **壊す**。1回で相手の貯金と石油の **1% ずつ**（上限なし）|
| 銀行のブロック | 壊れても **3秒で元に戻る**。**まわり3マスは掘ることも置くこともできない**（埋めたり下を掘ったりできない）|
| ビーコン | 相手の銀行を **100回**壊すと壊せるようになる → 植民地 |
| 下剋上 | 占領された側が **150円**で反撃の権利を買う（1勢力1つまで・近代から）|

### 同士討ち（2026-08-24 のご指示）

| | |
|---|---|
| **同じ勢力の仲間** | **傷つけられません**（殴っても矢でも銃でも通らない） |
| **敵の勢力** | 傷つけられます |
| 倒したとき | 相手の**個人の所持金の 10%** を奪う。**勢力の貯金からは取りません** |

## 4. 稼ぎ方と店（実装から）

| | |
|---|---|
| 掘る | 石・深層岩から貴金属。**銀行で売って個人の金**に |
| 石油 | プラントから湧く。**銀行に預けると勢力の石油**になる |
| 石油を売る | **中世から 1本 8円**（個人の金）|
| バブル | **中央が近代に入ると、貴金属の売値が 2倍**（全勢力に同時に効く）|
| 銃器専門店 | 勢力の**貯金が 10,000 を超える**と開く（一度 開いたら閉じない）|

**財布は2つ。** 個人の金（自分で稼ぐ）と 勢力の貯金（みんなの物）。
値段の表示は **「個人◯円」「勢力◯円」** で、どちらから引かれるかが分かります。

## 5. ガチャ（実装から）

| | |
|---|---|
| 1回の値段 | 鉄器 5円 / 中世 10円 / 近代 20円 / 現代 50円（十連はこの10倍）|
| 十連 | 10回ぶん。**伏せ札が1枚ずつめくれる** |
| 特殊アイテム | **5種**。勢力ごとに**各1個まで**（同じ物は二度 出ない）|
| 遺物 | **11種**。引くと**勢力の全員**に効果が付く |

> **★ 近代のガチャでは特殊が3種しか出ません**（護符・聖杯・海図）。
> **蒸気機関の歯車と月の石は現代のガチャだけ**です。
> だから5種そろえるには**現代まで進む**必要があります。
