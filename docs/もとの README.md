# 時代クラフト

**5つの勢力が、中央の石油を奪い合いながら、4つの時代を進める。**
勝つのは、いちばん早く「現代」へ到達した勢力。

- 石油は**中央にしか湧かない**。取りに行くには拠点を離れる
- 石油は**アイテム**。拾っただけでは数に入らず、**銀行で預けて初めて勢力の力になる**
- 預けた石油は奪われる。持ち歩いた石油は死ぬと落ちる。**どちらで持つかを選ぶ**
- 時代を進めるには **石油・貯金・建築** の3つが要る
- 足りなければ、**戦争を宣言して他の勢力から奪う**

> **この文書は運営向けの正本です。**
> **開発を引き継ぐ人（別のチャットを含む）は、先に [`次のチャットへ.md`](次のチャットへ.md) を読んでください。**
> 作法・いまの状態・残っている仕事・触ってはいけない場所がまとまっています。

## 導入手順

### 1. サーバーを起動する

`jikki_mod/start.bat` をダブルクリック。`Done (…)` と出れば起動完了です。

> **止める時は、黒い画面に `stop` と打って Enter。**
> 右上の × で閉じると、書きかけの世界が壊れます。

### 2. 拠点を建てる ── **これ1つだけ**

```
jidai setup
```

拠点5つと中央に施設を建て、プラグインに覚えさせるところまで全部やります。

```
[設置] 施設が 32 / 32 個 建ちました
[設置] 登録しました: 販売所 6 / 銀行 5 / ガチャ 5 / 進行 5 / かまど 10
[設置] 完了です。次は勢力へ入れてください
```

途中で足りなければ**自動で3回までやり直します**。

### 3. 参加者を勢力へ入れ、リーダーを決める

```
team join kyuryo Ronty8190
jidai leader set kyuryo Ronty8190
```

チーム名は `kyuryo`(丘陵) / `shinrin`(森林) / `kawa`(川) / `naikai`(内海) / `iwaba`(岩場)。
**リーダーでないと、時代進行の申請と下剋上ができません。**

## 勝利条件（4つ・すべて実装済み）

> **★ 番号が 1・3・4・5 と飛びます。**
> 2 は「人望勝利（傭兵の過半数）」でしたが、傭兵ごと止めました（2026-08-26）。
> **番号は詰めていません。** データパックの何箇所かに数字で書いてあり、
> 付け替えると黙って食い違うためです。

**どれか1つでも達成した勢力が勝ちです。** 決着してもサーバーは止まりません
（終わりの合図を派手に出すだけ。締めるのは運営）。

| # | 勝ち方 | 条件 |
|---|---|---|
| 1 | **戦争勝利** | 自勢力以外の**4勢力すべてを植民地**にする |
| 3 | **経済勝利** | 勢力の貯金が **500,000** に達する |
| 4 | **超特殊勝利** | **リーダーが特殊アイテム5種すべて**を持つ |
| 5 | **未来到達勝利** | **現代から「未来」へ進む**（本命。2026-08-23 に追加） |

> **★★ 「現代へ着くこと」は勝ちではありません（2026-08-23 のご指示）★★**
> 時代は **鉄器 → 中世 → 近代 → 現代 → 未来** の5つになりました。
> 現代はゴールではなく、**最後の1歩の手前**です。

### 1. 戦争勝利

1. 相手に**宣戦**して**交戦中**にする
2. 相手拠点の銀行を押して**略奪**し、相手の**貯金を 0 にする**
3. 相手拠点の**ビーコンが壊せるようになる**。壊すと相手は**植民地**
4. 自勢力以外の**4勢力すべて**を植民地にしたら勝ち

条件が欠けていれば理由が出ます（交戦中でない／貯金が残っている／自分の拠点）。

> **運営の準備**: 各拠点のビーコンを**勢力名つきで**登録してください。
> ```
> jidai beacon kyuryo
> ```

### 3. 経済勝利

勢力の貯金が **500,000** に達したら勝ち。
変えるなら `settei` の `経済_勝利_貯金`。

### 5. 未来到達勝利 ── 本命

**現代へ着いた勢力が、さらに「未来」へ進めたら勝ち。**

| 条件 | 値 | どういう壁か |
|---|---:|---|
| 石油の保有 | **500本** | 「**まだ持っているか**」の壁。腐敗（15分で10%）と略奪で下回る |
| 拠点の建材 | **2,400個** | 「**時間**」の壁。近代の 800 から +1,600 |
| 勢力の貯金 | **0円** | 要りません（ご指示に貯金が無いため） |

- 3条件が揃うと運営へ知らせが出ます。**承認した瞬間に、その勢力の勝ちです**
- 数字は `settei`（`進行_石油_現代` / `進行_建築_現代` / `進行_貯金_現代`）で変えられます

> **★ 石油を 550 以上にすると届かなくなります。**
> 2つめの勢力が現代に着くと中央が現代になり、**全勢力から石油を40%徴収**します。
> 先頭は約300本まで落ち、500本へ積み直すのに40分ほどかかるためです。
> **「2番手が現代に着く前に建て切れるか」がこの勝ち方の駆け引き**になります。
>
> **★ 建材を 6,912 より大きくすると、永久に届きません。**
> 数える区画が拠点中心から 24×12×24 だからです（`MiraiTest` が見張っています）。

### 4. 超特殊勝利

**リーダー1人が**、ガチャから出る特殊アイテム**5種すべて**を持てば勝ち。

| 特殊アイテム | 出る時代 |
|---|---|
| 古びた護符 | 鉄器から |
| 聖杯の欠片 / 羊皮紙の海図 | 中世から |
| 蒸気機関の歯車 / 月の石 | **現代だけ**（2026-08-23・案C） |

> 「勢力の誰かが持っていればよい」ではなく**リーダー1人に集める**形です。
> 5人で1つずつ持ったまま勝てないようにしています。

> **★ 近代では 3種までしか出ません（2026-08-23・案C）。**
> 前は近代で5種そろい、**57〜67分**で決着していました。本命の現代到達（当時 3時間12分）を
> 1時間 追い越していたので、残り2種を**現代のガチャ限定**にしました。
> いまの想定は **3時間17分〜3時間27分**（現代到達の 5〜15分 後）です。

#### 略奪で奪われる（2026-08-23・案D）

**交戦中に相手拠点の銀行を押して略奪が成立すると、金と石油に加えて、
相手勢力の【リーダー】が持っている紙を1枚 奪います。**

- 奪えるのは**集める5種だけ**。遺物は奪えません（効果は勢力に付いていて、紙では移らないため）
- **略奪が成立した時だけ**（クールダウン中や上限に達して断られた時は奪いません）
- リーダーが居ない・押した人の持ち物が満杯 なら、何も起きません
- 奪うと**全員へ通知**が出ます

集めるだけでなく**守り切る**必要ができ、終盤の戦争と噛み合います。

### ★★ 人を殴った時・殺した時（2026-08-24 のご指示）★★

**決まりは2つだけです。**

| # | 決まり |
|---|---|
| 1 | **同じ勢力の人間は傷つけ合えません**（殴っても弾いても通らない） |
| 2 | **人を殺すと、相手の【個人の金】の 10% をもらえます** |

**★ 勢力の貯金からは1円も取れません。** 取れるようにすると、1人を狩り続けるだけで
相手の時代進行を止められてしまうためです。

| 誰が誰を | 傷つけられるか | 奪えるか |
|---|---|---|
| 丘陵 → 丘陵（同じ勢力） | **できない** | – |
| 丘陵 → 森林（別の勢力） | できる | **10%** |

- 端数は**切り捨て**。10% が 0 になる相手（9円以下）からは何も動きません
- 自滅（自分で死んだ）では誰も奪えません
- 知らせは**当人2人だけ**に出ます。全体には出しません（戦闘は頻繁なので、チャットが流れて
  略奪や時代進行の知らせが読めなくなるため）

**止め方は二重にしてあります。**

| | |
|---|---|
| プラグイン | `Tatakai` が `EntityDamageByEntityEvent` で止める。**矢や弾は撃った人まで辿る** |

> **★ TaCZ の弾がプラグインのイベントに来るかは、実機でしか分かりません。**
> 来なくても、チームの `friendlyFire` は本体が直接 見るので保険になります。
> **実機で「味方に銃を撃つ」を必ず試してください**（`docs/実機確認リスト.md`）。

### ★ hire で雇うと、どうなるか

**しっかりその勢力のみに帰属します。** Minecraft のチームは**1人1つ**しか入れないので、

| | 雇われている間 |
|---|---|
| チーム | **雇い主の勢力**（名前の頭・色も勢力の物になる） |
| 同士討ち | **雇い主の勢力の一員として守られる** |
| 石油 | **勢力の合計には入らない**（`clock.mcfunction` が `scores={youhei=0}` で数えている） |
| 勢力の貯金 | **使えない**。何を買っても個人の金 |

  旧雇い主には**何も知らせません**し、払った石油も返りません
- 契約切れは**本人にだけ**知らせます（雇い主は残り時間を推測するしかない）

### ★★ 蛮族に勝利条件は【ありません】。これは設計です ★★

**Civ6 がモチーフだからです。** Civ6 の蛮族に勝利条件が無いのと同じで、
この企画の蛮族にも勝ちはありません。**穴ではないので、埋めないでください。**

蛮族の立ち位置はこうです。

| | |
|---|---|
| 勝ち | **無い。** しいて言えば「**勝ち馬に乗れ**」 |
| 面白さ | **自由で縛られない**。どの勢力の都合にも従わなくてよい |
| 見せ場 | **動画に爪痕を残せる**。勝敗の外側にいるので、何をしても筋が通る |
| 稼ぎ | **取引**。雇用料の石油を換金し、物を手渡しでやり取りする |

**取引が本当に成立することは実装で確かめてあります**（2026-08-24）。

- **手渡しは自由**。落とす・拾うを止めているイベントは1つもありません
- **石油は預けて初めて勢力の数に入る**ので、蛮族が渡した石油を勢力の人が預ければ勢力の物になります
- **石油を金に換えられるのは蛮族・傭兵だけ**（1本 12円。勢力は銀行で 8円）
- **金そのものは受け渡せません**（個人の金はスコア）。だから**石油が事実上の通貨**になります

> **★ 覚えておく取引の筋（実装から出てくる形）**
> → 手渡しで勢力へ渡す。**銃器専門店の「貯金 10,000 超」を通さずに銃が手に入ります。**
> 蛮族の銃は勢力の上位（M107）を超えないうえ、石油を払う側の進行が遅れるので、
> 割に合うかは場合によります。**止めていません**（これこそ取引なので）。

## 石油の扱い

**石油はアイテムです。拾っただけでは数に入りません。**

| | 持ち歩いている石油 | 銀行に預けた石油 |
|---|---|---|
| 死んだ時 | **落とす** | 減らない |
| 他人に渡す | できる | できない（引き出せば渡せる） |
| 時代進行の条件 | 入らない | **入る** |
| 略奪・徴収 | されない | **される** |

銀行（金ブロック）の **「石油を預ける」** で預けます。引き出しは `/trigger sekiyu_dashi set <本数>`。

### 勢力ごとの獲得上限

**上限 = 今の時代を進めるのに要る石油 × 1.2**

| 時代 | 進めるのに要る | 上限 |
|---|---|---|
| 鉄器 | 100 | **120** |
| 中世 | 250 | **300** |
| 近代 | 500 | **600** |
| 現代 | —（進む先が無い） | **600** |

上限に達したら、預けても数に入りません（**手元へ返します**。捨てられません）。
時代を進めると上限も上がります。

> 傭兵と無所属には勢力の上限がありません（勢力の合計に混ざらないため）。

## 販売所の品揃え

### ★ ピッケルは売っていません ── 配る1本きりです

**全員に「時代のツルハシ」を1本ずつ配ります。** 初めてサーバーに入った時に
自動で渡るので、運営が何か打つ必要はありません。

| | |
|---|---|
| 壊れない | 耐久がまったく減りません |
| 死んでも落とさない | その場に残らず、生き返った時に手元へ戻ります |
| 1人1本 | 店では売っていません。**二度目は配られません** |

> **なぜ売らないのか**
> クラフトが禁止なので、ツルハシが壊れると二度と掘れません。
> 買い直す形にすると「金が無い → 掘れない → 金が稼げない」という
> 抜け出せない詰み方が起きます。壊れない1本にして、
> 掘ること自体は誰にでも常にできる状態にしてあります。

無くした人（溶岩に落とした等）には運営が渡し直せます。

```
jidai tsuruhashi <名前>
```

> **手で捨てることはできます。** 止めているのは「死んだ時に落とすこと」だけです。

## リソースパック（UI）── **配りません**（2026-08-21 決定）

**買い物画面は、クライアント側の MOD が描きます**（`clientmod/`）。
リソースパックでチェスト画面の背景を差し替える方式は取りやめました。
理由は絵の質ではなく**方式の上限**です ── 横 176px 固定・枠が 18px 刻み・
文字を絵に焼くしかない・変わる数字が出せない。詳しくは `次のチャットへ.md` の §6-A。

**配るものは今までどおり3ファイルだけです**（銃の MOD / 音声チャット / 銃のデータ）。
**リソースパックは足しません。**

> **★ 入れると副作用があります。**
> 第3回の納品は4案とも `assets/minecraft/lang/` で `container.inventory` を
> 空文字に上書きしています。**入れているあいだ、チェスト・かまど・MOD の画面からも
> 「持ち物」の字が消えます。`jidai ui off` では戻りません**
> （あれはプラグイン側の文字だけを切り替えるものだからです）。
> 焼き込んだ文字と重ならないようにするための処置で、**MOD へ移った今は不要です。**

**納品物は消していません。** `resourcepack/codex/` にそのまま残してあります。

- `02_Navigation`（地図・航海）の意匠を、**MOD の見た目の下敷きにします**
- 各案の `SCOREBOARD_TEXT.txt`（サイドバーの文字案）は **MOD になっても使います**
  ── サイドバーはクライアントが直接描いており、**MOD でも絵にできません**

`jidai ui on` / `off` のコマンドは残していますが、**使いません**（既定は `off`）。
