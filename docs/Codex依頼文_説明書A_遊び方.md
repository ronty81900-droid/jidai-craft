## 0. これは何か

**100人が参加する Minecraft の催し「時代クラフト」の、参加者に配る説明書です。**

同時に2冊 作ります。こちらは **A「遊び方」＝ 絵をたくさん使う方**です。
（B「詳細版」は別紙 `Codex依頼文_説明書B_詳細版.md`。**AとBで絵柄と色をそろえてください**）

### 誰が読むか

**開始10分前に、初めてこの企画を知る人。**
Minecraft は遊べますが、この企画のことは何も知りません。

- **高校生が読んで分かる言葉**にしてあります。漢字は使ってかまいません
- 100人のうち、かなりの人が**文字を読まずに絵だけ見ます**
- そのつもりで、**絵だけ追えば遊べる**ものにしてください

### いちばん大事なこと

> **文章はこちらで確定しています（§3）。1文字も足さず、削らず、書き換えないでください。**
> ご担当いただくのは **①イラスト ②組版（レイアウト）** の2つです。
> 文章に不足を感じたら、絵を足さずに**こちらへ質問**してください。

### 絵柄

**ゲーム内の画面と地続きに見えること。** この企画の UI は「古地図・測量図」の見た目です。

- **平らな面で塗る**（強いグラデーション・写実的な陰影を避ける）
- 輪郭は暗い色の線
- 人物は**顔を描かない**（Minecraft のスキンは人それぞれなので、頭は四角いシルエットで）
- **奥行きは斜め見下ろし**（Minecraft の等角図に寄せる）

| 見出しの水色 | `#4FA1B2` | ページ見出し |
| 金 | `#E8B44A` | 「勝ち」「大当たり」に関わる所だけ |

### 表紙（1ページ目）

- **大見出し**: `時代クラフト`
- **小見出し**: `遊び方`
- **絵 `e01`（世界の全体図）**: 中央に石油プラント（黒い塔）。それを囲むように5つの拠点が放射状に並ぶ**俯瞰図**。
  5拠点は §2 の勢力色で塗り分ける。空は夕方の色。全体を古地図の枠で囲む。
- 隅に小さく: `5つの勢力 / 100人 / 石油を奪い合う3時間`

### 2ページ目「これは、どういう遊びか」

**見出し**: `これは、どういう遊びか`

**本文**:
```
あなたは5つの勢力のどれかに入ります。
中央にしか湧かない石油を奪い合い、
```

**絵 `e03`（時代の階段）**: 左に「鉄器」の粗末な小屋 → 右へ「中世」「近代」「現代」「未来」と建物が育っていく
**5コマの横並び**。足元に矢印。右端の「未来」だけ金色に光らせる。

★ あわせて **`e02`（5つの勢力）**を、このページの下に帯で入れてください。
　丘陵（白）森林（緑）川（水色）内海（青）岩場（金）の旗を横に5本。**単独の PNG でも書き出す**（B が使います）。

### 11ページ目「戦争」

**見出し**: `戦争のやりかた`

**本文**:
```
販売所で「戦争宣誓」を買い、相手を選びます。
準備5分のあと、10分だけ戦えます。
仲間は傷つけられません。敵を倒すと所持金の 10% を奪えます。
```

**絵 `e15`（戦争を宣言する）・`e16`（準備と交戦）・`e17`（略奪する）・`e18`（ビーコンを壊す）**: **4コマ**（横並び・矢印でつなぐ）。
★ **4コマは1枚ずつ別の PNG としても書き出してください**（B が e17 を単独で使います）。
- ① 販売所で戦争宣誓を買う
- ② 砂時計（準備5分）
- ③ 敵拠点の金ブロックを**壊して**、相手の貯金と石油を **1% ずつ**奪う
- ④ **100回 壊すと**ビーコンが壊せる → 花火が上がる → 相手は植民地になる

★ **③は「押す」ではなく「壊す」です。**ツルハシを振り下ろし、
　金ブロックが砕けて欠片が飛ぶ絵にしてください。
★ **④のビーコンは、光の柱が折れて花火が上がる絵**にしてください。

★ **`e21`（味方は殴れない）**: 同士討ちができないことを、**②と③のあいだに小さく**入れてください。
　同じ色の2人のあいだに剣を置き、**×印**を重ねる。
★ **`e22`（倒すと奪える）**: 敵を倒して相手の所持金の一部が自分へ移る絵も、小さく1つ。
　この2枚も**単独の PNG で書き出してください**（B が使います）。

★ **`e25`（銀行のまわりは掘れない）**: このページの隅に**小さく1つ**。
　金ブロックを囲む**3マスぶんの枠に×印**を重ね、その横に**砂時計**を置く。
　「掘れない・置けない」と「3秒で戻る」の2つが一目で分かる形にしてください。
　**この絵も単独の PNG で書き出してください**（B が使います）。
　キャプション（絵の外に組版で載せる）:
　`金ブロックは3秒で戻ります。まわり3マスは掘れません・置けません`
