## §1 当日の進行

### 1-1. 開始の 30分前（1回だけ・ゲーム内で）

| # | 打つもの | 確かめること |
|---|---|---|
| 1 | `/jidai scan` | 販売所・銀行・ガチャ・進行・かまどの件数が出る。**「見つからなかった」で終わっていないか**。0件でも今の登録は消えないので、成功と勘違いしやすい |
| 2 | `jidai game` | プラントと5拠点の座標が出る。**「未登録」が1つでもあれば 1 に戻る** |
| 3 | `jidai game beacon` | 5拠点の後方に鉄3×3＋ビーコン＋勢力色のガラスが建つ。ビームが5本 立っているか目で見る |
| 4 | `/jidai leader set <勢力> <名前>` ×5 | `/jidai leader` で5勢力ぶん出るか |
| 5 | `/jidai craft` | **【建材だけ】**と出ること。`kyoka` になっていたら `kinshi` に戻す |

> **★ 3 と 4 は `scan` の後**。拠点の位置が決まっていないとビーコンが建ちません。

### 1-2. 開始（コマンドブロック1つで）

チェーンコマンドブロックに、この順でつなぎます（**スラッシュは付けない**）。

```
1. jidai game reset zenbu    ← 練習の痕跡を消す
2. jidai game risu           ← 勢力のリスポーンを拠点に
3. jidai game tp kyoten      ← 勢力を拠点へ
4. jidai game start          ← 石油が湧き始める
```

**★ `reset zenbu` の直後は「停止中」です。6 の `start` を必ず打ってください。**
**★ 結果はコマンドブロックの「前回の出力」に出ます。** 人数や「未登録」の知らせはそこで読みます。

### 1-3. 進行中に GM がやること

| いつ | やること |
|---|---|
| **常時** | **時代進行の承認**（§3）。これだけは人間が開けます |
| 誰かが「ツルハシを無くした」 | `/jidai tsuruhashi <名前>` |
| 進行が遅い／速い | §4 の調整 |

### 1-4. 終了

決着が出ても**サーバーは止まりません**（派手な合図が出るだけ）。締めるのは人です。

```
jidai sekiyu tomeru    ← 石油を止める（拾う人が散らないように）
jidai game stop        ← 全員に「ゲーム停止」のタイトル
```

> **★ `stop` が止めるのは石油の栓だけです。** 戦争・腐敗・時代判定・サイドバー・所持金の帯は動き続けます。
> 時計ごと止めるとサイドバーも止まり、**「止めた」のか「壊れた」のか参加者に見分けが付かない**ためです。

### 2-3. `jidai game`（運営のゲーム操作）

> **★★ 2026-08-24 に足した確認用の2つ ★★**
>
> ```
> jidai game tokushu            集める5種＋遺物11種の【紙】を全部 出す
> jidai game tokushu 月の石     その1枚だけ出す
> jidai game ibutsu ロスチャイルドの金庫   その遺物の【効果】を自分の勢力に付ける
> jidai game ibutsu             遺物11種の一覧を出す
> ```
>
> **絵を見比べる時は `tokushu`、効果を確かめる時は `ibutsu`** です。
> ガチャは 0.5% なので、狙って出せません。この2つが無いと確認そのものができません。
>
> - `tokushu` は**紙を出し、遺物なら効果も付けます**（勢力に入っていれば）
> - `ibutsu` は**効果だけ**。紙は出ません。勢力に入っていないと付きません（効果は勢力に付くため）
> - **`jidai game ibutsu`（引数なし）の一覧は、勢力に入っていなくても出ます**
>
> **★★ スマートフォンだけ、紙を持っている本人も `/joho` を使えます（2026-08-24）★★**
> ほかの遺物の効果は今までどおり【勢力】に付き、紙を渡しても移りません。
> `/joho` は本人が自分で打つ物なので、**買った・奪った・運営が出した紙**でも効きます。
> - どちらも**ガチャの記録（勢力ごとに各1個）には触りません**
> - `jidai game reset` で効果は消えます

**足元が要るのは `spawn here` と `kyoten <勢力>` の2つだけ。**ほかはコマンドブロックから打てます。

| 書式 | 中身 |
|---|---|
| `jidai game start` | 石油の栓を開ける ＋ 全員に「ゲーム開始」 |
| `jidai game stop` | 石油の栓を閉じる ＋ 全員に「ゲーム停止」 |
| `jidai game reset` | 中央=1／各勢力=1／湧き=0／銃器の解放を取消／中央ビーコンの色／**特殊アイテムの記録を初期化（遺物の効果も切れる）** |
| `jidai game reset zenbu` | 上＋ 貯金・個人の金・石油・占領・植民地・下剋上・勝利・戦争 ＋ **手元の特殊アイテムを取り上げる** ＋ 停止中にする |
| `jidai game risu` | 勢力の全員の bed spawn を拠点に（**ベッドがある人はベッドを尊重**） |
| `jidai game spawn` / `spawn here` / `spawn <x> <y> <z>` | 初期リスポーン（既定 **`40 176 -927`**） |
| `jidai game kyoten <勢力>` | 今の足元を拠点の立ち位置に（走査より優先） |
| `jidai game beacon` | 5拠点の**立ち位置の16ブロック後方（-z）**にビーコンを建てて登録 |

> **★ `zenbu` は完全一致でしか効きません。** `zenb` と打つと**黙って軽い方のリセット**になります。
> 同じく `risu` は3語目が `youhei` 以外だと**黙って勢力側**になります（`tp` だけは使い方を出します）。

## §3 時代進行の承認 ── GM の唯一の必須作業

**数えるのは機械、開けるのは人間**です。条件が揃っても、**GM が承認するまで時代は進みません**。

### 3-1. 承認のしかた

```
function jidai:shinko/shounin_kyuryo    ← 丘陵
function jidai:shinko/shounin_shinrin   ← 森林
function jidai:shinko/shounin_kawa      ← 川
function jidai:shinko/shounin_naikai    ← 内海
function jidai:shinko/shounin_iwaba     ← 岩場
```

承認は**その場でもう一度3条件を確かめます**。崩れていたら
「◯◯ は条件を満たしていない。承認しなかった」と出て、何も起きません。**空振りしても安全です。**

### 3-2. 承認すると何が起きるか

1. **その勢力の貯金から、必要額がそのまま引かれる**（5,000 / 15,000 / 50,000 / **現代→未来は 0**）
2. その勢力の時代が1つ上がる
3. その勢力の全員に「新しい商品が並びました」／全員に効果音
4. **2つの勢力が同じ時代に到達していたら、中央の時代が上がる** → 湧きの数えが0に戻り、**全勢力から石油を40%徴収**
5. **★★ 上がった先が「未来」（時代5）なら、その瞬間に その勢力の勝ちです ★★**
   全員に「★ 未来到達勝利 ★」が出ます。**承認が決着の合図**になるので、押す前に間違いがないか確かめてください

### 3-3. 見張り方

参加者は「時代を進める」の画面で申請します。**申請そのものは GM に自動で飛びません。**
チャットか、`jidai game` の一覧で条件の達成を見て判断してください。

> **★ GM の反応が遅いと、そのぶん催しが延びます。** 承認は「見たらすぐ」。
> 空振りが安全なので、**迷ったら打ってよい**設計です。

## §4 進行の調整

### 4-1. 想定時間（`docs/クリア想定時間.md` の要約）

| 勝ち方 | 想定 |
|---|---:|
| **未来到達勝利**（現代 → 未来） | **2時間30分〜2時間40分**（本命。現代到達＋建てる時間 15〜25分） |
| 超特殊勝利（特殊5種） | **2時間18分〜2時間28分**（現代到達の 5〜15分 後） |
| 　（参考）現代へ着くまで | **2時間13分**（1時間40分〜3時間29分） |
| 戦争勝利 | 実質 2時間以上 |
| 経済勝利（50万） | **5.9時間**（バブル後。3時間では届きません。§4-4） |

**催しの枠は3時間を推奨**します。

### 4-2. 当日に効くつまみ

すべて `/scoreboard players set <項目> settei <値>` で変えられます。

| 何を | 既定 | 変えると | 効き |
|---|---:|---|---|
| `石油_倍率` | 100 | `jidai sekiyu osaeru <1〜100>` で変える | 湧きの速さ。**100=通常 / 50=半分** |
| `腐敗_減少率` | 10 | 5 に下げる | **現代到達が約20分 早くなる**（いちばん効く） |
| `進行_石油_近代` | 500 | 400 に下げる | 最後の壁だけを緩める |
| `リセット_徴収率` | 40 | 20 に下げる | 中央が上がった時の落ち込みを浅く |
| `戦争_準備秒` | 300 | 短くする | 戦争のテンポ |
| `経済_勝利_貯金` | 500000 | 150000 に下げる | 経済勝利を現実的に |

> **★ `石油_間隔_鉄器`〜`_現代` は `/reload` で必ず 10 に戻ります**（`unless` を付けずに毎回 上書きしているため）。
> **遊んでいる最中の調整は `jidai sekiyu osaeru` を使ってください。**
> **★ イベント中に `/reload` を打たないこと。**

### 4-4. 経済勝利はまだ届きません（要 判断）

2026-08-23 の救済（バブル ×2 ＋ 石油 8円）で **10.9時間 → 5.9時間**になりましたが、
**3時間の催しではまだ届きません**。届かせるには `経済_勝利_貯金` を下げてください。

| 目標 | 到達 |
|---|---:|
| 500,000（今） | 5.8時間 |
| 300,000 | 3.6時間 |
| **200,000** | **2.6時間**（3時間の催しの終盤で決着） |
| 150,000 | 2.0時間 |

```
scoreboard players set 経済_勝利_貯金 settei 200000
```

### 4-3. 決まったこと（2026-08-23）

**① 超特殊勝利は案C＋D で抑えました。もう最速ではありません。**

| | 前 | 後 |
|---|---|---|
| 5種そろう時代 | 近代 | **現代だけ**（近代の景品表から「蒸気機関の歯車」「月の石」を外した） |
| 想定 | 57〜67分 | **2時間18分〜2時間28分** |
| 守る危険 | 無し | **略奪でリーダーから1枚 奪われる**（§5-5-2） |

**② 「現代へ着くこと」は勝ちではありません。「未来」へ進めたら勝ちです。**

時代は **鉄器 → 中世 → 近代 → 現代 → 未来** の5つになりました（`#shouri_shu` に **5=未来到達** を足した）。

| 現代 → 未来 の条件 | 値 | どういう壁か |
|---|---:|---|
| 石油の保有 | **500本** | 「まだ持っているか」の壁。腐敗と略奪で下回る |
| 拠点の建材 | **2,400個** | 「時間」の壁。近代の 800 から +1,600 |
| 勢力の貯金 | **0円** | 要りません |

> **★ この勝ち方の駆け引き**
> 2つめの勢力が現代に着くと中央が現代になり、**全勢力から石油を40%徴収**します。
> 先頭は約300本まで落ち、500本へ積み直すのに40分ほどかかります。
> **「2番手が現代に着く前に建て切れるか」**が分かれ目です。
>
> **★ 石油を 550 以上にすると届かなくなります**（上の徴収のため）。
> **★ 建材を 6,912 より大きくすると永久に届きません**（数える区画が 24×12×24 のため）。
> どちらも `MiraiTest` が見張っています。

> **★★ 建築 2,400 は実機で測っていません ★★**
> `tests/clear_time.py` の模型は石油と貯金しか数えないので、
> 建築にかかる時間だけは**1回まわすまで分かりません**。20人で 15〜25分 と見ています。
> 長すぎ／短すぎなら `scoreboard players set 進行_建築_現代 settei <値>` の1行で変えられます。

| 1 | 銀行の枠が「10 預ける / 50 預ける / 全部 預ける」 | **「10円 / 50円 / 全額貯金」**へ |
