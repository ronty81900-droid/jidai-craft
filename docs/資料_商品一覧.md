### 店が開く条件（ソースの記述そのまま）

`Shop.jukiKaihouMiru(plugin, kuni, chokin)` / `Ibutsu.jukiShikii(kuni)`:

| 項目 | 内容 |
|---|---|
| しきい値（通常） | `Shop.JUKI_KAIHOU = 10000` |
| しきい値（遺物「武器商人の手形」を持つ勢力） | `Ibutsu.JUKI_SHIKII_TEGATA = 5500` |
| 判定式 | `if (chokin <= Ibutsu.jukiShikii(kuni)) return false;` → **「超えた時」に開く。ちょうど 10,000（手形なら 5,500）では開かない** |
| 見るもの | 勢力の貯金（chokin）。**中世に入っただけでは開かない** |
| 永続性 | 一度でも超えたら**その勢力は恒久的に開く**。`plugin.getConfig()` の `juki_kaihou.<勢力>` に書き出し、起動時に `jukiYomikomi` が読み戻す |
| なぜ「今の残高が10,000以上の間だけ」にしなかったか | 12,000 の狙撃銃を買った瞬間に店が閉じ、「買えたのに買えなくなる」という説明のつかない挙動になるため |
| 開いた後 | 今までどおり**時代ごとに銃が順に解禁**される（下表の解禁時代） |
| 閉じている時の見た目 | 全枠が灰色ガラス板「？？」＋「勢力の貯金が 10000 を超えると店が開きます」 |
| リセット | `Shop.jukiRisetto(plugin)` で記録を全消去 |

※ `Shop.java` 454行目のコメントは「（手形があれば 5,000）」と書いてあるが、実際の定数 `Ibutsu.JUKI_SHIKII_TEGATA` は **5500**。数字はコメントではなく定数を採った。

補足:

### 抽選のきまり（ソースより）

- 重みは **10000 を1万分率**として使う（例: 1500 = 15.00% / 50 = 0.50% / 10 = 0.10%）。各時代の重み合計はちょうど 10000。
- 時代ごとに景品表を**総入れ替え**する。`jidai` 欄は「この時代**だけ**に出る」の意味。**見るのは中央の時代**。
- 等級（`toukyuu`）: ハズレ / 小 / 中 / 大。止まった時の音と、全体に流すかどうかが変わる。
- 「大当たり」の見出しが出るのは **お金と特殊アイテムだけ**（`oomonoKa`）。
- 金の景品は**個人の金をその額だけ増やす**。アイテムは渡さない（画面の金塊は見た目だけ）。
- 十連には天井: 10個の中に「中」以上が1つも無かった時だけ、最後の1つを「中以上だけの抽選」で引き直す。**天井の引き直しは特殊アイテムを対象にしない**。
