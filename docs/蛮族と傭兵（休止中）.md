## 1. どんな仕組みだったか

### 1-1. 立場

| 呼び名 | 何者か |
|---|---|
| **蛮族** | 5勢力のどこにも属していない人。名前の頭に `[蛮族] ` が付く |
| **傭兵** | 蛮族が勢力に雇われている間の呼び名。契約が切れるとまた蛮族に戻る |

**蛮族に勝利はありません。** civ6 が下敷きなので、civ6 の蛮族に勝利が無いのと同じです。
立ち位置は「勝ち馬に乗れ」。自由で縛られず、動画に爪痕を残せる立場でした。

### 1-2. 雇用の流れ

```
/hire <名前> <石油の量>      雇い主が申し出る
      ↓ 60秒で失効
/yes                        傭兵側が承諾（/no で断る）
      ↓
契約成立 …… 現実時間で 60分
      ↓
自動で終了 → また蛮族へ戻る
```

| コマンド | 誰が | 何をする |
|---|---|---|
| `/hire <名前> <石油>` | 雇い主 | 申し出る |
| `/yes` `/no` | 傭兵 | 受ける／断る |
| `/headhunt <名前> <石油>` | 別の勢力 | **契約中の傭兵を引き抜く** |
| `/youheimise` | 蛮族・傭兵 | 蛮族の店を開く（MOD の U キーと同じ） |
| `jidai youhei <名前>` | 運営 | 蛮族にする |
| `jidai kaijo <名前>` | 運営 | 契約を切る |
| `jidai keiyaku` | 運営 | 契約の一覧 |

**雇用料は石油**でした。金ではなく石油にしたのは、
勢力にとって石油が時代進行の資源で、痛みを伴う支払いになるからです。

### 1-3. 蛮族の店（U キー）

**未雇用の蛮族と、雇われている傭兵の両方**が使えました。27枠・3段・タブ3枚。

| タブ | 中身 |
|---|---|
| 一般 | 剣・弓・食料 |
| 銃器 | **銃5丁と弾4種**。★ 勢力の銃器専門店と**1丁も重ならない** |
| 売る | 貴金属を売る・**石油を売る**・残高の札 |

**★ なぜ銃を重ねなかったか**
同じ銃を2割引きで並べると「自分で買うより傭兵に買わせる方が安い」になり、
勢力の貯金で銃を買う意味が薄れるためです。別系統にすることで、
傭兵は「勢力に無い武器を持ち込む人」になり、雇う理由が立ちました。

### 1-4. 石油の扱い（ここが要）

| | 勢力の人 | 蛮族・傭兵 |
|---|---:|---:|
| 石油の売値 | 8円 | **12円** |
| 勢力の石油合計に入るか | **入る** | **入らない** |
| 銀行 | 使える | **断られる** |

蛮族の石油が勢力の合計に入らないのは、`clock.mcfunction` の
`@a[team=kyuryo,scores={youhei=0}]` で除いていたためです。
**これが時代到達の見積りを大きく変えていました**（現代到達 2:13 → 3:12）。

> **★ 「蛮族王・傭兵王 KUN」は、この記録から外しました（2026-08-29 のご指示）。**
> 復活させる時も **KUN 陣営は作りません**。傭兵と蛮族だけを戻します。

### 1-6. 戦い方の違い

| | |
|---|---|
| 同じ勢力の仲間 | 殴れない（`Tatakai.java`） |
| **蛮族どうし** | **殺し合える**（仲間うちでも可） |
| 敵・蛮族を倒す | 相手の**個人の所持金の10%**を奪う（勢力の貯金からは取らない） |
| チームの `friendlyFire` | 5勢力は `false` / **`youhei` は `true`** |

## 3. 戻す時に気を付けること

1. **石油の見積りが変わります。** 傭兵の石油は勢力の合計に入らないので、
   戻すと時代到達が遅くなります（現代到達 2:13 → 3:12 の差）。
2. **`friendlyFire` の設定**が `load.mcfunction` に要ります。5勢力 `false` / `youhei` `true`。
3. **`/yes` と `/no` は plugin.yml でクォートが必須**です。
   YAML は裸の `yes` / `no` を真偽値とみなすので、`'yes'` `'no'` と書かないと
   「Unknown command」になります。
