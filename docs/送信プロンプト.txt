添付の Markdown 3つのうち、`Codex依頼文_*` の2つが**仕様書**です。
`資料_商品一覧.md` は、仕様書Bが「この表をそのまま入れてください」と指している**表の元**です。

**この仕様どおりに、参加者向けの説明書 2冊を作成してください。**

## 作ってほしいもの

**① `JidaiCraft_Manual_A_v8.zip`** ── 仕様書『説明書A「遊び方」』のとおり

```
JidaiCraft_Manual_A_v8.zip
├── JidaiCraft_遊び方.pdf         ← A4横・12ページ
├── pages/                        ← p01〜p12 の PNG（3508×2480）
├── illust/                       ← ★ 使ったイラストを1枚ずつ（e01〜e24）
├── DESIGN_SPEC.md
└── manifest.json
```

**② `JidaiCraft_Manual_B_v8.zip`** ── 仕様書『説明書B「詳細版」』のとおり

```
JidaiCraft_Manual_B_v8.zip
├── JidaiCraft_詳細版.pdf         ← A4縦・22ページ
├── pages/                        ← p01〜p22 の PNG（2480×3508）
├── DESIGN_SPEC.md
└── manifest.json
```

★ **B のイラストはすべて A の `illust/` からの流用です。新規作画はありません。**

## 担当していただくこと

**①イラストの作成 ②組版（レイアウト）** の2つだけです。文章はすべて仕様書で確定しています。

## 守っていただくこと（受け入れ時に機械で検査します）

1. **文章と表は仕様書のとおり。1文字・1数字も変えないでください。**
   丸める・単位を変える・カンマを足す・並べ替える、もすべて不可です。
   数字はゲームの実装から機械で抜き出したもので、**1つでも違うと説明書として嘘になります。**

2. **PDF の文字はテキストとして埋め込んでください**（検索・選択できること）。**絵に焼き込まないこと。**
   ── こちらは PDF から文字を取り出して、仕様書の文章と1文字ずつ突き合わせます。

3. **色は仕様書A §2 のパレットのみ。** パレット外の色を使わないでください。

4. **★★ 生成イラストを使ってください（前回までと逆です）★★**
   第3回〜第7回は「画像生成モデルを使わないこと」とお願いしていましたが、
   **今回はその決まりを取り下げます。生成イラストを多用してください。**
   - 生成した絵をそのまま使ってかまいません
   - ただし **パレットに寄せる後処理**（色調整）をしてください
   - **絵柄は12ページで統一**すること
   - **生成した絵の中に文字を入れないでください。** 文字はすべて組版で上に載せてください

5. ページ数・寸法・ページの順番を仕様書のとおりに（**A は12 / B は22**）。

6. `manifest.json` に各 PNG の sha256・寸法・使用色を入れてください。

## 進め方のお願い

- **A を先に仕上げてください。** A で決まった絵柄・パレット・書体・イラストを、そのまま B で流用します。
  A の受け入れが済んでから B に着手していただく形で構いません。

- **A の納品には `illust/` を必ず入れてください。** B はここから絵を取ります。
  ファイル名は `e01_世界の全体図.png` のように、仕様書A §4 の番号で。

- **ゲーム内画面の絵**（ガチャ・販売所・拠点）が必要でしたら、**こちらからスクリーンショットをお出しします。**
  推測で描かず、お声がけください。

- 説明書B の銃のページは、**実銃の細部を描かず、輪郭のシルエットだけ**にしてください。

- **仕様どおりに作れない箇所**（表が1ページに収まらない、この文章では絵にしにくい、等）が出たら、
  **勝手に調整せず、こちらへご相談ください。** 文章側をこちらで直します。
