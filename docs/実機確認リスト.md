## 0. 準備（1回だけ）

```
op <自分の名前>
gamemode creative
team join kyuryo <自分の名前>
scoreboard players set <自分の名前> kane_kojin 200000
```

**確かめる間だけ腐敗を止めるなら:**
```
scoreboard players set 腐敗_猶予秒 settei 99999
```

> ★ 本番（`jikki_mod`）の世界は難易度「平和」（level.dat の Difficulty=0）で、敵は湧きません。
> **控えの `jikki_1201` の世界は「ノーマル」のまま**（Difficulty=2）で、夜にゾンビが湧きます
> （server.properties の `difficulty=peaceful` は、今ある世界には効いていなかった。2026-09-28 実測）。
> 控えを使う時は、最初に1回 `difficulty peaceful` を打ってください（世界に保存されます）。

## ★★ 終わったら必ず戻す（`/reload` では戻りません）★★

設定値（`settei`）は「**まだ入っていない時だけ**入れる」書き方なので、
`/reload` でも `jidai game reset zenbu` でも**元に戻りません**。
戻さずに本番へ入ると、**腐敗が止まったまま・準備5秒のまま**の催しになります。

**変えた物を消してから `/reload`** すれば、データパックが本来の値を入れ直します。

```
scoreboard players reset 腐敗_猶予秒 settei
scoreboard players reset 戦争_準備秒 settei
scoreboard players reset 戦争_交戦秒 settei
scoreboard players reset 略奪_間隔秒 settei
scoreboard players reset 占領_必要回数 settei
scoreboard players reset 進行_建築_現代 settei
reload
jidai game reset zenbu
```

## 2. マルチでしか確かめられない物

### 2-a. ボットで確かめる物（Claude が担当）── ★ 2026-09-28 に済み（21項目）

`jikki_1201`（Paper・MOD 無し）の**写し**に、ボットを4体（丘陵 Kyu1・Kyu2／森林 Shin1・Shin2）と
後から1体（Kyu3）入れて確かめた。
写しには**いまの元**（`plugin.yml` の版の jar と `datapacks/jidai_craft`）を入れる。本番へ配る前にここで確かめられる。
**銃（TaCZ）と MOD の画面は、ここでは確かめられない**（2-b）。

```
node tests/bot_kakunin.js
```
これ1本で「写しを作る → WMI で起動 → 確かめる → 止める → 写しを消す」まで済む（約6分）。
本物の `jikki_1201` は読むだけ。写しだけオフライン認証にして、`127.0.0.1` 以外からは入れないようにしてある。
「起きない」を確かめる項目には、同じ形で【起きる】対照を必ず付けてある（矢が外れただけ、を数えないため）。
最後に一度 起動し直して、「落ちた時の保険」（残った戻し待ちの印が起動時に外れる）も見る。
**結果（v0.60.0）: 46 PASS / 0 FAIL**（2026-09-28。①「文は出ない」を確定して、期待を揃えた）

**同士討ちの禁止と、キルで 10% 奪取**
- [x] 同じ勢力の仲間を剣で殴れない（体力 20 のまま）
      ★ **「同じ勢力の仲間は傷つけられません」の文は出ない。これで確定（2026-09-28 のご判断）。**
      バニラのチームの `friendlyFire=false`（データパックの `load`）が、
      プラグインの門（`Tatakai.fusegu`）より**先に**黙って止めるため。
      その間だけ `friendlyFire true` にすると、プラグインが止めて文が出る（体力はやはり 20）。
      ＝守りは二重（1枚目＝チーム、2枚目＝プラグイン）。ボットの検査も「文は出ない」を期待にした
