# ソロ検証の順路 ── 1人でどこまで確かめられるか

> **★ 蛮族と傭兵は 2026-08-26 に止めました。**
> 「内容が細かくなりすぎる。裏道は消して、戦いをメインに」というご判断で、
> **今回は5勢力のバトルだけ**にしています。
> 仕組みの記録と戻し方は **[蛮族と傭兵（休止中）.md](蛮族と傭兵（休止中）.md)**。

最終更新: **2026-08-26**（プラグイン v0.55.0）

> **答え: 123項目のうち、約103項目（8割）は1人で確かめられます。**
> 2人以上が要るのは **約20項目**で、そのほとんどが「殴る・撃つ」です。
>
> 1人で通せる理由は2つ。
> **① `team join` で勢力を自由に移れる**（バニラのコマンド）
> **② 相手の勢力は【プレイヤーが居なくても】成立する**（貯金も石油も時代もスコアなので、
> `/scoreboard` で作れる。宣戦も相手がログインしていなくても通る＝実装を読んで確認済み）

---

## 0. 始める前に（1回だけ）

```
/gamemode creative
/op <自分の名前>
```

```
scoreboard players set <自分の名前> kane_kojin 200000
```

**この2つを覚えておくと、ほぼ何でも作れます。**

| やりたいこと | 打つもの |
|---|---|
| 勢力に入る／移る | `team join kyuryo <自分>` （kyuryo / shinrin / kawa / naikai / iwaba） |
| 個人の金を作る | `scoreboard players set <自分> kane_kojin 200000` |
| 勢力の貯金を作る | `scoreboard players set 丘陵 chokin 60000` |
| 石油を作る | `scoreboard players set <自分> sekiyu 600` |
| 中央の時代を変える | `scoreboard players set 世界 chuo 2` （1鉄器 2中世 3近代 4現代） |
| 勢力の時代を変える | `scoreboard players set 丘陵 jidai 4` |
| 建材の数を作る | `scoreboard players set 丘陵 kenchiku 2400` |
| 特殊アイテムを出す | `jidai game tokushu` |
| 遺物の効果を付ける | `jidai game ibutsu <名前>` |
| 全部 戻す | `jidai game reset zenbu` |

> **★ 手で入れた石油は、上限では削られません**（上限が掛かるのは「預ける」時だけ）。
> ただし **15分ごとに腐敗で 10% 減ります**。ゆっくり確かめるなら先に止めてください。
>
> ```
> scoreboard players set 腐敗_猶予秒 settei 99999
> ```
>
> **★ 検証が終わったら `jidai game reset zenbu` と `/reload` で戻すこと。**
> `settei` をいじったまま本番に入ると、腐敗が効かない催しになります。

## 1. ソロで完全にできるもの（約103項目）

### A. ガチャ（26項目）── まず ここから

```
team join kyuryo <自分>
scoreboard players set <自分> kane_kojin 200000
scoreboard players set 世界 chuo 1
```
拠点のダイヤブロックを押して、単発・十連・天井・演出・特殊アイテムを一通り。

**近代と現代のガチャの中身（案C）を見るには:**
```
scoreboard players set 世界 chuo 3
```
十連を10回ほど回して、出る特殊が **護符・聖杯・海図の3種だけ**であること。そのあと
```
scoreboard players set 世界 chuo 4
```
で **歯車と月の石も出る**こと。

### B. 特殊アイテムと遺物（20項目）

```
jidai game tokushu
```
16枚 出ます。**暗い5つ（金庫・手帳・ゴーグル・スマートフォン・転炉）を並べて見分けられるか**はここで。
勢力に入っていれば効果も同時に付きます。

```
jidai game ibutsu
jidai game ibutsu ロスチャイルドの金庫
```
効果を1つずつ付けて確かめられます（売値1.2倍・手形5,501・手引書の戻し・鉄王冠・聖剣・盾・スマホ）。

### C. 販売所・銀行・掘り・クラフト・掲示板（23項目）

```
team join kyuryo <自分>
scoreboard players set 丘陵 chokin 20000
```
→ 銃器専門店が開く。**銀行で 10円 → 50円 → 貴金属を売る → 石油を売る が続けて押せるか**（8/24 に直した所）。
未開放の枠にカーソルを乗せて**名前が「？？」のまま**か（8/26 に直した所）。

### D. 戦争・略奪・制圧（11項目）★ 1人でできます

**相手の勢力にプレイヤーは要りません。**

```
team join kyuryo <自分>
scoreboard players set 丘陵 chokin 5000
scoreboard players set 森林 chokin 400
```
拠点の販売所で「戦争宣誓」を買い、森林を選ぶ。
森林の拠点へ行き、**金ブロックを押す**（宣戦前・準備中・交戦中の3つの返事を見る）。

```
scoreboard players set 戦争_準備秒 settei 5
```
にすると準備が5秒で終わり、待たずに交戦へ入れます。

**ビーコン破壊まで:**
```
scoreboard players set 森林 chokin 50
```
→ 森林のビーコンが壊せる。花火5発・「終戦」・植民地化まで1人で見られます。

### E. 未来到達勝利（11項目）★ 1人でできます

```
team join kyuryo <自分>
scoreboard players set 丘陵 jidai 4
scoreboard players set <自分> sekiyu 600
scoreboard players set 丘陵 kenchiku 2400
```
拠点の鉄ブロックを押す → 3条件が揃う → 申請 →
```
function jidai:shinko/shounin_kyuryo
```
→ **「未来到達勝利」のタイトルとかなとこの音**（8/26 に足した所）。

**4つの勝ち方のタイトルを全部 見るなら:**
```
scoreboard players set 世界 shouri 0
scoreboard players set #s_kuni sagyou 1
scoreboard players set #shouri_shu sagyou 3
function jidai:sensou/shouri_kakutei
```
`#shouri_shu` を **1・3・4・5** に変えて打ち直せば、4種類とも見られます（★ **2 は空振り**します。人望勝利だった番号で、今は使っていません）
（★ 打つ前に毎回 `世界 shouri` を 0 に戻すこと。二度目は出ません）。

### F. 運営コマンド（8項目）・見た目（4項目）

`jidai game start / stop / reset / tp kyoten / risu / spawn / beacon` を順に。

## 2. ★ どうしても2人 要るもの（約20項目）

| 章 | 数 | なぜ1人では無理か |
|---|---:|---|
| **同士討ちの禁止・10%奪取** | **11** | 殴る相手・撃つ相手が要る。Mob では代用できません（プレイヤー限定の判定） |
| **2人の画面が混ざらないか** | **5** | 本質的に2人 |
| **案D（略奪で紙を奪う）** | **4** | 相手のリーダーが紙を持っている状態が要る |
| その他 | 数件 | 「別々の向きに降りる」など、複数人でしか見えない物 |

> **★★★ この中で最優先は1つだけです ★★★**
> **「同じ勢力の仲間に【銃】を撃っても当たらないか」。**
> TaCZ の弾がプラグインのイベントに来るかは、**ここでしか分かりません**。
> 来なければプラグインの門を素通りします（チームの `friendlyFire=false` が保険ですが、
> 効いているかも実機でしか確かめられません）。
>
> **2人 集められる時が来たら、まずこれを試してください。** 2分で終わります。

### 2人目を用意する手

- **もう1台の PC / もう1つのアカウント**でログインする
- **オフラインモードのテストサーバー**なら、同じ PC から2つ起動して別名で入れます
  （`jikki_1201/server.properties` の `online-mode=false`。★ 本番の `jikki_mod` は触らないこと）
