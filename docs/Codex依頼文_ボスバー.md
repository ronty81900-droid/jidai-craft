# 依頼: 世界の時代バー（ボスバー）の絵

Minecraft のイベント「時代クラフト」で、画面の上に出す**進捗バー**の絵をお願いします。
既にあるUI（販売所・銀行・ガチャ）と同じ**古地図風**で揃えてください。

---

## 何に使うか

参加者60〜70人が5つの勢力に分かれ、鉄器時代から未来を目指します。
このバーは**世界全体が次の時代にどれだけ近いか**を示します。

- **2つの勢力が次の時代の条件を満たすと、世界の時代が上がります**
- バーはその進み具合で伸び、時代が上がると**空に戻ります**
- 動きは **7段階**（0/6, 1/6, 2/6, 3/6, 4/6, 5/6, 6/6）

数字は出しません。**バーの伸びと色だけで、視聴者に世界の状態が伝わる**のが狙いです。

---

## 作ってもらう画像

### 1. `bar_frame.png` ── 枠（空の状態）

| | |
|---|---|
| 大きさ | **728 × 40 px** |
| 内訳 | 枠の内側の「溝」が 720 × 24 px、上下左右に 4px の縁 |
| 背景 | 透過（PNG・アルファ付き） |

バニラのボスバーは 182×5px しかありません。**4倍の解像度**で作ってもらい、
クライアントMODが縮小せずそのまま描きます。

### 2. `bar_fill.png` ── 中身（満タンの状態）

| | |
|---|---|
| 大きさ | **720 × 24 px** |
| 使い方 | 左から `幅 × 進捗` だけ切り出して描きます |

★ **左端から切ります。** 中央から広がる、両端から詰まる、といった作りにはしないでください。
★ **縦方向は一様に**してください。上下でグラデーションを付けるのは構いませんが、
  横方向の模様が場所によって変わると、切った時に不自然になります。

### 3. `bar_fill_<時代>.png` ── 時代ごとの中身（4枚）

世界の時代が上がるごとに色が変わります。**同じ形・同じ大きさで、色だけ変えた4枚**をください。

| ファイル | 時代 | 色の方向 | 手持ちの色 |
|---|---|---|---|
| `bar_fill_tekki.png` | 鉄器 | くすんだ灰白 | `#AEB8AE` |
| `bar_fill_chusei.png` | 中世 | 真鍮・古びた金 | `#C4934B` |
| `bar_fill_kindai.png` | 近代 | 青緑 | `#4FA1B2` |
| `bar_fill_gendai.png` | 現代 | 明るい薄紫 | `#B9A7D0` |

## 色の決まり（既にあるUIの正本）

この4色は勝手に変えないでください。ほかの画面と揃っています。

| 役割 | 色 | どこに使うか |
|---|---|---|
| 地 | `#102329` | いちばん外側 |
| 板 | `#685E45` | 枠の本体 |
| 明るい縁 | `#B2A577` | 枠の上と左のハイライト |
| 暗い縁 | `#1B282B` | 枠の下と右の影 |
| 溝 | `#38474A` | 中身が入る前の空の部分 |
| 文字 | `#F5E8C8` | 文字を置く場合 |

## 古地図風とは（このUIでの決まり）

既にある画面と同じ作りにしてください。

- **羊皮紙のような、少しくすんだ色**。彩度は高くしない
- **1px の硬い縁取り**。ぼかさない
- **紙の繊維のような細かいノイズ**を薄く乗せる。ただし切っても不自然にならない程度に
- **斜めのハッチング**は使わない（横に切ると縞がずれて見える）
- 角は**直角**。丸めない

参考として、既存の画面の絵を同じフォルダに置きます。
`clientmod/ui/assets/jidaiui/textures/gui/` の `page_*.png` と `card_compact_*.png` を見てください。

---

## 描き方の決まり

**画素で描いてください。** ベクターから書き出した滑らかな絵ではなく、
1画素ずつ意味のあるドット絵にしてください。拡大縮小は最近傍で行います。

**アンチエイリアスを掛けないでください。** 中間色が増えると、
バーを切った時に縁がにじみます。

**色数は1枚あたり32色までに抑えてください。** 少ないほど古地図らしくなります。

## 納品の形

```
nouhin/bossbar/
├── bar_frame.png            728 x 40
├── bar_fill_tekki.png       720 x 24
├── bar_fill_chusei.png      720 x 24
├── bar_fill_kindai.png      720 x 24
├── bar_fill_gendai.png      720 x 24
├── preview_empty.png        枠だけの見え方（8倍に拡大した物）
├── preview_half.png         3/6 まで伸びた見え方（4枚ぶん）
├── preview_full.png         満タンの見え方（4枚ぶん）
└── DESIGN_SPEC.md           使った色の一覧と、この依頼文の sha256
```

**プレビューは本番の画像を最近傍で拡大した物にしてください。** 別に描き起こさないでください。
こちらで画素を突き合わせて確かめます。1画素でも違えば受け取れません。

`DESIGN_SPEC.md` には、**この依頼文の sha256** を書いてください。
どの版の仕様で作ったかが分からないと、直しの往復が増えます。

---

## 確かめること（こちらで機械にかけます）

1. 大きさが指定どおりか
2. 色数が32色以内か
3. アンチエイリアスの中間色が入っていないか
4. 4枚の `bar_fill_*` が**形は同じで色だけ違う**か（アルファの形が一致するか）
5. プレビューが本番の最近傍拡大と1画素も違わないか
6. 左から任意の幅で切っても、縁が破綻しないか
