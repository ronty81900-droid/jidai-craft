## 3. 戦争 ── **プラグインは勢力名の保持者だけを読む**

> **★★ 1.20.1 移行でここだけ作りが変わりました ★★**
> 1.21 では保持者 `丘陵>森林` のスコアで戦争を持っていました。
> その名前はマクロ（`$(...)`）でしか作れず、**1.20.1 にマクロがありません**（実測）。
> そこで **マーカー1体＝戦争1件** に変えました。
> マーカーのスコアは「そのマーカーとして」でないと読めないため、
> データパックが毎秒 **勢力名の保持者へ写し直します**（`jidai:sensou/youyaku`）。

### プラグインが読んでよいのは、この3つだけ

| 目的（保持者＝勢力名） | 意味 |
|---|---|
| `sensou` | 0=なし / 1=準備 / 2=交戦 / 3=再戦禁止 |
| `sensou_aite` | 交戦相手の**番号**（0=なし） |
| `sensou_byou` | 今の状態の残り秒 |

- 1勢力が同時に持てる戦争は **1つだけ**（要約は最初に見つけた1件を写す）
- **毎秒作り直される派生値です。** プラグインが書き込んではいけません
- `sensou_tsuyosa` は作業用。読まないでください
- **マーカーは読まないでください**

### 宣戦の呼び方（**引数は渡せません**）

1.20.1 に関数の引数（マクロ）はありません。**先にスコアへ置いてから**呼びます。

```
scoreboard players set #w_kuni sagyou 1     ← 宣戦する側の番号
scoreboard players set #w_aite sagyou 2     ← される側の番号
scoreboard players set #w_soku sagyou 0     ← 0=ふつう / 1=即交戦（下剋上）
function jidai:sensou/sensen
```

**3つとも必ず置くこと。** 前回の値が残っていると別の戦争が始まります。
番号は `bangou` から引けます（`scoreboard players get 丘陵 bangou` → 1）。

> **断られたことは、呼び出し側からは分かりません。**
> `sensen` は条件に合わないと `return 0` するだけで、命令自体は成功に見えます。
> そのため呼んだあと **`function jidai:sensou/youyaku` を呼んでから**
> `sensou` を読み直し、1以上になっていなければ返金してください。

### 略奪の呼び方

```
execute as <名前> at <名前> run function jidai:sensou/aite_yomu
execute as <名前> run scoreboard players operation #jibun_no sagyou = @s bangou
execute as <名前> at <名前> run function jidai:sensou/ryakudatsu
```

**`with storage` は 1.20.1 にありません。** 番号をスコアで渡します。

## 5. サイドバー ── **勢力ごとに別のものを出す**

1つの目的を `sidebar` へ出すと全員が同じものを見ます。
**自分の勢力の情報だけ見せる**には、表示枠を分けるしかありません。

`sidebar.team.<色>` は**そのチームの色の人にだけ**映る枠です（1.20.1 に在ることは実測済み）。

| 表示枠 | 目的 | 勢力 |
|---|---|---|
| `sidebar.team.white` | `hyouji_1` | 丘陵 |
| `sidebar.team.green` | `hyouji_2` | 森林 |
| `sidebar.team.aqua` | `hyouji_3` | 川 |
| `sidebar.team.blue` | `hyouji_4` | 内海 |
| `sidebar.team.gold` | `hyouji_5` | 岩場 |
| `sidebar.team.gray` | `hyouji_0` | 傭兵 |
| `sidebar`（素） | `hyouji_0` | どのチームにも居ない人 |

**★ 表示枠の色は `team modify … color` と必ず揃えること。** ズレるとその勢力に何も映りません。

出すのは **貯金 / 石油 / 中央の時代 の3行だけ**。1人が見る行は常に3行です。

> **個人の金はサイドバーに出せません。** 保持者ごとに1行なので、出すと勢力の全員が
> 並んでしまいます。画面下の帯（`title @s actionbar`）へ毎秒出しています。
> `list`（Tab の一覧）にも `kane_kojin` を出しています。

## 7. 石油アイテムの見分け方

1.20.1 にアイテムコンポーネントはありません。**NBT の `tag`** で見ます。

```
minecraft:black_dye{jidai_sekiyu:"oil"}
```

| 印 | 意味 |
|---|---|
| `jidai_sekiyu:"oil"` | 石油であることの印。**これが拾得の検知の鍵** |
| `moto:"chuo"` | 中央プラント産（引き出した石油には**付かない**） |

地面の石油は `Age:-32768`（歳を取らない印）と `Invulnerable:1b` を持ち、
**消えず、溶岩でも燃えません**（実測）。

## 8. プラグインが書いてよいもの / 書いてはいけないもの

### 書いてよい（実測: `Kane.java` が `setScore` しているもの）

- `chokin`
- `kane_kojin`
- `sekiyu`
- `youhei`
- **`settei` の `石油_停止` と `石油_倍率` だけ**（2026-08-20 追加）

  > ★ `settei` は原則データパックの持ち物だが、この2つだけ例外。
  > 運営が `jidai sekiyu tomeru / hajimeru / osaeru <1〜100>` で動かす。
  > 例外にしてよい理由は、データパック側がこの2つを
  > `scoreboard players add 石油_停止 settei 0` のように
  > **「無ければ作る・あればそのまま」** で置いており、毎秒上書きしないため。
  > 他の `settei` は `execute unless … matches 1..` で初期値を決めるだけなので、
  > 書き換えても読み込み直しで戻る。**書いてよいのはこの2つに限る。**

### 書いてはいけない

- `sensou` / `sensou_aite` / `sensou_byou` … **毎秒作り直される派生値**
- `sekiyu_gokei` … 同上
- `senryou` / `gekokujo` … 占領と権利はデータパックが決める（**金も引かない**）
- `bangou` / `jidai` / `chuo` … データパックの持ち物
- `settei` … **上の2つ（石油_停止 / 石油_倍率）以外は書かない**
- 戦争のマーカーのスコア全部
