Minecraft企画「時代クラフト」のルールブックを、イラスト付きPDFで2種類作ってください。
**イラストは全点、画像生成AIで作ります。**

## 2種類の違い

- 【こども版】小学生でも分かる。ふりがな多め、短い文、1ページ1トピック。
  絵で理解できることを最優先。ルールの網羅より「何をすればいいか」が分かること
- 【くわしい版】高校生以上向け。全ルール網羅、数値・例外・判定方法まで記載。
  運営が採否を判断できるレベルの詳細さ

## 絵の作り方（最重要）

全部 画像生成AIで描いてください。ただし「それっぽい絵を並べただけ」にならないよう、次の8つを守ってください。

### 1. 画風を1つに決めて、最後まで動かさない

下から1つ選んでください。**混ぜないこと。** 迷ったら B を推します。

- **A 厚塗りのゲームコンセプトアート** … 油彩調、夕方の斜光、広い空、遠景に構造物
- **B レトロな博覧会ポスター**（推し） … 1950年代の万博ポスター調。色数を絞る、太い輪郭、堂々とした構図
- **C 木版画・浮世絵風** … 線が主役、平塗り、紙の目が見える

**B を推す理由**: この企画は「時代が5段階に上がっていく」話です。
博覧会ポスターは元々「これから来る未来を売る」ための絵なので、話の骨と噛み合います。
色数が少ないので、ページを跨いでも絵が揃って見えます。

### 2. いちばん最初に「画風の見本」を3枚だけ作る

本編に入る前に、次の3枚を作って見せてください。ここで画風を決めます。

1. 中央の石油プラント（遠景・時代1の姿）
2. 勢力の拠点（近景・人が働いている）
3. 資源のアイコン4種を1枚に（石・鉄・石油・金）

**この3枚が決まったら、以降は必ずこれを参照画像（スタイル参照）に入れて生成してください。**
毎回ゼロから作ると、ページごとに絵柄が変わります。

### 3. ★ 文字を絵の中に入れない

**画像生成AIは日本語を必ず崩します。** 看板・見出し・数字・矢印の注記は、
**あとから組版で乗せてください**。生成する絵には文字を入れないこと。

- 画像プロンプトに毎回 `no text, no letters, no numbers, no signage, no watermark` を入れる
- 文字を置きたい場所は、**絵の側を空けておく**（空・地面・単色の帯など、上に文字を置ける面を作る）
- 「絵の中に説明が描いてある」ような図解（吹き出し付きの説明図など）を生成AIに描かせない。
  **図解は組版側で作る**（線と四角と、生成した絵の切り抜きを組み合わせる）

### 4. 1枚ごとに、使ったプロンプトを残す

あとで1枚だけ差し替えたくなります。**画像ごとに、使ったプロンプト・ネガティブプロンプト・
シード・モデル名を書き出して納品してください。**（`prompts.md`）

### 5. ★ 人物の描き方

- **顔を描かない。** 後ろ姿、シルエット、フードや兜で隠す、遠景の小さい人影 ── のどれかにする
- **実在の人物に似せない。** この企画には実在の参加者（KUN さん含む）が出てきますが、
  **似顔絵にしないでください**。役割（傭兵・リーダー）を服装と持ち物で表す
- 手を大きく写さない（生成AIが崩しやすい）

### 6. ★ Minecraft の公式アセット・スクリーンショットを使わない

権利の問題です。**全部 描き起こしてください。**
「四角いブロックで出来た世界」という雰囲気は出してよいですが、
公式のテクスチャ・UI・ロゴ・キャラクターをそのまま使わないこと。
プロンプトに `Minecraft` という単語を入れず、`blocky voxel world`, `cubic terrain` のような一般語で書いてください。

### 7. ネガティブプロンプト（全点 共通で入れる）

```
text, letters, numbers, watermark, signature, logo, UI, interface, HUD,
human face, portrait, celebrity likeness,
extra fingers, deformed hands,
photo, photorealistic, 3d render, cgi,
oversaturated, neon glow, lens flare, bokeh
```

### 8. 色と縦横比

- **色は6色まで**に絞ってください。全ページで同じ6色を使う
  （草・石・鉄・石油・炎・空 をイメージした色。具体的な値は §2 の見本で決める）
- 見開きの大きい絵 … 横長 16:9
- ページ内の挿絵 … 正方形 1:1
- 表紙・扉 … 縦長 3:4
- **解像度は 300dpi 相当**（A4 縦なら 2480×3508）

### 今回も禁止するもの

「AIっぽさを消す」はもう求めませんが、次の2つは**中身が薄くなる**ので今回も禁止です。

- **意味のないインフォグラフィック**（数字が入っていない円グラフ、飾りだけの図）
- **同じ構図の使い回し**（毎ページ中央に丸いものが1つ、のような）

## 文章の書き方

- 定型的な前置き（「本書では〜」等）を書かない
- **話しかけるような文体**で書く
- 【こども版】は 1ページ1トピック。ふりがな多め、1文を短く
- **数字は「ゲームの内容」に書いてある値をそのまま使う。**
  丸めない・足さない・言い換えない。**書いていない数字は作らない**
  （すべて実装から読んだ確定値です。ここが食い違うと、配ったルールで遊べません）

## ゲームの内容（これをルール化してください）

> ★★ **ここは「企画案」ではなく、いま動いている実装です**（2026-08-23・プラグイン v0.41.0）。
> 数字はすべてソースとデータパックから読んだ値で、`python tests/bunsho_kakunin.py` が
> 248項目で見張っています。**数字を勝手に丸めたり足したりしないでください。**

### ■一言でいうと

「時代を進める石油は、地図の中心に1か所しかない」
5つの勢力に分かれ、鉄器時代から現代まで**4つの時代**を登っていく。

### ■人数

**5勢力 × 20人 ＝ 100人 ＋ 傭兵 25人 ＝ 125人。**

### ■時代（5つ）

**鉄器 → 中世 → 近代 → 現代 → 未来。**（企画案にあった「石器」は廃止しました）

**★ 現代はゴールではありません。**「未来」へ進めた勢力が勝ちます（下の勝ち方 5）。
★ 中心のプラントの姿が変わるのは現代までの4段階です（未来は勢力だけの時代）。

時代には2種類あります。混ぜないでください。

| | 何を表すか | 何に効くか |
|---|---|---|
| **勢力の時代** | その勢力がどこまで進んだか | 販売所・銃器専門店に並ぶ品 |
| **中央の時代** | 中心のプラントの姿 | 石油の湧く総量・ガチャの中身・先行ペナルティ |

**2つの勢力が同じ時代に到達すると、中央の時代が上がります。**
その瞬間、石油の数えが 0 に戻り、**全勢力から石油を 40% 徴収**します。

### ■勢力（5つ）

**丘陵 / 森林 / 川 / 内海 / 岩場。** どこにも属さない人は「傭兵」です。

### ■マップ

中心に石油プラントが1つだけ。各勢力の拠点は中心から等距離。
プラントは**中央の時代（4段階）**で姿が変わります。

各拠点にあるもの: 販売所 / 銀行（金ブロック）/ ガチャ / 時代を進める鉄ブロック /
エンダーかまど / **ビーコン**（後方16ブロック。壊されると制圧される）。

### ■時代を進める条件（3つ全部を満たす）

| いまの時代 | 石油の保有 | 勢力の貯金 | 拠点の建材 |
|---|---:|---:|---:|
| 鉄器 → 中世 | 100本 | 5,000円 | 200個 |
| 中世 → 近代 | 250本 | 15,000円 | 400個 |
| 近代 → 現代 | 500本 | 50,000円 | 800個 |
| **現代 → 未来** | **500本** | **0円（要りません）** | **2,400個** |

**★ 3つ揃っても、運営が承認するまで進みません。**「数えるのは機械、開けるのは人間」です。
承認すると、**貯金から必要額がそのまま引かれます**。

**★★ 現代 → 未来 が承認された瞬間、その勢力の勝ちです。**

### ■石油のルール

- 湧くのは**中央だけ**。**10秒に4本**（4か所へ1本ずつ）
- 中央の時代ごとの総本数: **鉄器 750 / 中世 1,800 / 近代・現代 3,350本**
- 中央の時代が上がると数えが 0 に戻り、また湧く
- **石油はアイテム**。持ち歩いていると**死んだ時に落とします**。銀行に預ければ減りません
- 溜め込むと**腐ります**（15分 使わなければ 10% 減る）
- **中世からは、手持ちの石油を銀行で 1本 8円 で売れます**（預けた石油は減りません）
- 各勢力の保有量は**サイドバーで全員に公開**されます

### ■先に進んだ勢力へのペナルティ

**中央より先へ進んだ勢力は、石油を拾う時に半分 失います。**（＋ 光って位置が分かります）

### ■お金

| 個人の金 | 勢力の貯金 |
|---|---|
| 食料・松明・原木・石レンガ・ガラス・金リンゴ・**矢・弾**・ガチャ | 剣・弓・クロスボウ・防具・**銃**・戦争宣誓(100)・下剋上(150) |

稼ぎ方は**石を掘って出る貴金属を銀行で売る**こと（鉄1 / ラピス5 / 金10 / ダイヤ15 / ネザライト30）。
**近代以降はバブルで貴金属の売値が2倍**になります。

### ■買い物

- **販売所** … 生活 / 武器 / 防具 のタブ。並ぶ品はその勢力の時代で決まる
- **銃器専門店** … **勢力の貯金が 10,000 を「超えた」瞬間**に開く（ちょうど 10,000 では開かない）。
  一度 開いたら二度と閉じません。開いた後も銃は時代ごとに順に解禁
- **ガチャ** … 個人の金。単発と十連。値段は中央の時代で 5 / 10 / 20 / 50円
- **蛮族の店**（蛮族・傭兵だけ） … 剣・食料・**銃器**・**貴金属と石油を売る**。勢力とは**別系統の銃**が並ぶ

### ■蛮族と傭兵

**同じ人です。違いは「雇われているか」だけ。**

| | 呼び名 | 頭に付く字 |
|---|---|---|
| 雇われていない | **蛮族** | `[蛮族] ` |
| 勢力に雇われている | **傭兵** | 雇い主の勢力の物 |

- どこにも属さない人。**石油で雇われる**。**契約は60分**
- **蛮族の店（U キー）** … 剣・食料・銃器と、**貴金属・石油を売る**。雇われても開いたまま
- **石油は 1本 12円 で売れます**（勢力の人は 8円）。**石油を金に換えられるのは蛮族・傭兵だけ**
- 勢力の銀行は使えません（預ける・略奪は勢力のもの）
- **特殊アイテムは1つも出ません**。戦争宣誓・下剋上も買えません
- 拾った石油は**どの勢力の合計にも入りません**（＝勢力の助けにはならない）

**★★ 蛮族に勝利条件はありません。これは設計です（Civ6 の蛮族と同じ）★★**

勝ちを狙う立場ではなく、**自由で縛られない立場**です。しいて言えば「勝ち馬に乗れ」。
稼ぎは**取引**です ── 雇用料の石油を換金し、買った物を手渡しでやり取りします。
**金そのものは渡せない**ので、**石油が事実上の通貨**になります。

> ルールブックでは「蛮族は勝てません」と正直に書き、
> **そのかわり何をしてもよい立場だ**と伝えてください。禁止事項の列挙にしないこと。

### ■戦い（人を殴る・殺す）

- **同じ勢力の仲間は傷つけられません**（殴っても弾いても通りません）
- **人を殺すと、相手の【持っている個人の金】の 10% をもらえます**
- **勢力の貯金からは1円も取れません**
- **蛮族は仲間うちでも殺し合えます**
- 雇われた傭兵は、雇い主の勢力の一員として守られます

### ■勝ち方（4つ・どれか1つ）

| # | 勝ち方 | 条件 |
|---|---|---|
| 1 | **戦争勝利** | 自勢力以外の**4勢力すべてを植民地**にする |
| 3 | **経済勝利** | 勢力の貯金が **500,000** に達する |
| 4 | **超特殊勝利** | **リーダー1人**が特殊アイテム**5種すべて**を持つ |
| 5 | **未来到達勝利** | **現代から「未来」へ進む**（石油 500本 ＋ 建材 2,400個）← **本命** |

> **★★ 「現代へ到達したこと」自体は勝ちではありません。**
> 現代はゴールの手前です。そこから **石油を持ったまま拠点を建て切って**、
> 「未来」へ進めた勢力が勝ちます。

**戦争勝利の手順**: 宣戦 → 準備 → 交戦 → 相手の銀行を**略奪**して貯金を 100 以下にする →
**ビーコンを壊す**と植民地。これを4勢力ぶん。

**超特殊勝利の特殊アイテム5種**:

| 名前 | 出る時代 |
|---|---|
| 古びた護符 | 鉄器から |
| 聖杯の欠片 / 羊皮紙の海図 | 中世から |
| 蒸気機関の歯車 / 月の石 | **現代だけ** |

- ガチャから **1種につき 0.5%** で出ます。**近代までに集められるのは3種まで**
- **勢力ごとに各1個まで**（一度 出た種類は、その勢力ではもう出ません）
- **略奪されると、リーダーが持っている紙を1枚 奪われます。**集めるだけでなく守り切る必要があります

### ■遺物（11種）── 集めても勝ちにはならない

ガチャから出る別系統のアイテム。**手に入れた勢力の全員に効果**が付きます（移動速度・攻撃力・
被ダメージ減・採掘速度・売値・暗視 など）。**紙を奪われても効果は移りません。**

### ■植民地にされた勢力

**下剋上**を起こせます。**勢力の金 150・近代以降・1勢力につき1回だけ。**

### ■画面に出る情報

- **サイドバー**: 各勢力の時代・貯金・石油（常時）
- **チャット**: 時代進行・大当たり・略奪・制圧・勝利
- **画面中央の大きな文字**: 開始・時代が上がった時・終戦
